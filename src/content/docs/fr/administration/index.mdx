Gérez l’installation de CDelivery et les ressources utilisées par vos applications.

## Gestion de base

1. Sélectionnez un serveur dans la liste pour consulter son état, ses ressources et ses métriques.
2. En tant qu’administrateur, ouvrez la gestion des utilisateurs dans les paramètres pour créer des comptes et attribuer des rôles.
3. Ouvrez votre compte pour changer le mot de passe, configurer l’authentification à deux facteurs ou gérer les clés API.
4. Ouvrez CDelivery dans les paramètres pour consulter la version, mettre à jour la plateforme ou configurer son domaine.

Reader peut consulter les informations partagées, Operator peut aussi gérer les opérations des applications et Admin gère les paramètres de la plateforme et les comptes.
