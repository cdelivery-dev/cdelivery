XHealth vérifie régulièrement le comportement de l’application, notamment les parcours essentiels comme la connexion des utilisateurs.

## Créer un contrôle

1. Ouvrez l’onglet **XHealth** de l’application.
2. Importez un fichier Hurl ou saisissez une commande de test personnalisée.
3. Choisissez la cible et l’intervalle du test, puis activez le contrôle.
4. Consultez le dernier état et les messages d’erreur dans l’onglet XHealth. Utilisez les journaux de l’application pour analyser les échecs.

Activez Guardian pour utiliser aussi ces contrôles lors des mises en production.
