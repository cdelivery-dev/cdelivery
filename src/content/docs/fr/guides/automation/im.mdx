Connectez des canaux de messagerie à CDelivery pour les conversations et les notifications d’exploitation.

1. En tant qu’administrateur, ouvrez **Paramètres → Canaux** et choisissez Slack, Telegram, Discord, Lark ou Feishu.
2. Renseignez les identifiants du bot ou de l’application demandés sur la page, puis enregistrez.
3. Dans **Compte**, ouvrez le même canal et associez votre propre identifiant utilisateur immuable en suivant les indications.
4. Après avoir configuré l’[assistant IA](/docs/fr/guides/automation/), envoyez un message privé au bot pour démarrer une conversation.
5. Activez les notifications sur la page du canal de votre compte si nécessaire ; choisissez leur langue dans **Paramètres → Agent → Astreinte**.

L’association du compte et les notifications se règlent séparément.
