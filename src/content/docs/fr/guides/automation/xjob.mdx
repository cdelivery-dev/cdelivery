Utilisez XJob pour exécuter des commandes d’application selon un calendrier ou lancer une tâche manuellement.

1. Ouvrez la page **XJob** d’une application et créez une tâche avec un nom et une commande.
2. Choisissez un intervalle ou une planification par calendrier ; pour le calendrier, indiquez les jours, les heures et le fuseau horaire.
3. Créez la tâche. Sur sa page de détails, cliquez sur **Exécuter maintenant** pour la lancer manuellement.
4. Consultez le dernier résultat et la prochaine exécution dans les détails ; en cas d’échec, l’erreur est affichée.

Les commandes s’exécutent dans un nouveau conteneur utilisant l’image de l’application.
