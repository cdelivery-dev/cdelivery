Connectez des outils externes à CDelivery via l’API REST ou MCP.

1. Ouvrez **Compte → Clés MCP / API** et créez une clé avec un nom, un rôle et une date d’expiration facultative.
2. Copiez la clé, affichée une seule fois, et envoyez-la sous la forme `Authorization: Bearer YOUR_API_KEY`.
3. Pour REST, essayez `GET /api/me` et ouvrez `/scalar` dans le navigateur pour consulter la documentation de l’API.
4. Pour MCP, utilisez l’adresse `/mcp` de votre instance et la même authentification Bearer.

Tous les chemins correspondent à votre instance CDelivery. Une clé ne peut pas accorder plus de droits que le rôle actuel de son propriétaire.
