XConfig distribue les fichiers de configuration à plusieurs instances de service, sans intégrer de SDK ni maintenir un service de configuration supplémentaire.

1. Créez une application ou ouvrez sa page de configuration.
2. Ajoutez un fichier de configuration dans la section des fichiers et du stockage.
3. Importez le fichier et indiquez son chemin absolu dans le conteneur, par exemple `/etc/app/config.conf`.
4. Validez la création ou la mise à jour pour monter le fichier au démarrage du conteneur.
5. Pour modifier le fichier par la suite, importez son remplacement et mettez à jour l’application. Vous pouvez aussi télécharger le fichier actuel.

XConfig et les volumes de données locaux ne peuvent pas être utilisés dans la même application.
