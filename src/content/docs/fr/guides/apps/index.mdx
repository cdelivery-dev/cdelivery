Gérez l’image, les paramètres d’exécution et les mises à jour de l’application au même endroit.

1. Ouvrez l’application, puis sa page de configuration.
2. Modifiez au besoin l’image, le nombre de répliques, la commande de démarrage ou les variables d’environnement.
3. Envoyez la mise à jour.
4. Consultez l’état des conteneurs dans la vue d’ensemble. Redémarrez l’application ou, si l’option est disponible, annulez la dernière modification.

Les applications utilisant des volumes de données locaux exécutent une seule réplique sur le serveur sélectionné.
