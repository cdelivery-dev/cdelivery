Déployez une application à partir d’une image de conteneur sur votre propre serveur.

## Déploiement

1. Créez ou ouvrez un groupe dans le tableau de bord, puis choisissez de créer une application.
2. Saisissez un nom et l’image d’une application HTTP. Commencez avec une réplique.
3. Dans les ports et domaines, ajoutez une correspondance TCP avec le port de l’application dans le conteneur et un port public libre.
4. Créez l’application et vérifiez l’état du conteneur sur la page de présentation.
5. Ouvrez `http://SERVER_IP:PUBLIC_PORT` dans votre navigateur avec l’adresse IP du serveur et le port public choisi.

Le port du conteneur doit correspondre au port d’écoute de l’application. Autorisez l’accès au port public dans le pare-feu ou le groupe de sécurité.
