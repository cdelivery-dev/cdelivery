CDelivery est une plateforme d’exploitation auto-hébergée pour déployer des applications, gérer les domaines et HTTPS, planifier des tâches et consulter les journaux et les métriques.

## Ce que vous pouvez faire

- Organiser les applications en groupes, déployer des images de conteneur et distribuer les fichiers de configuration avec XConfig.
- Acheminer les requêtes vers les applications avec Pingress et gérer automatiquement les certificats HTTPS.
- Vérifier les parcours métier avec XHealth et activer Guardian pour valider les nouvelles versions avant leur publication.
- Collecter les journaux applicatifs, les accès et les métriques des serveurs avec Insight, sans intégrer de SDK.
- Planifier les commandes récurrentes avec XJob et utiliser l’assistant IA pour analyser et diagnostiquer les problèmes.

Commencez avec un serveur, puis augmentez les ressources selon les besoins de vos applications.
