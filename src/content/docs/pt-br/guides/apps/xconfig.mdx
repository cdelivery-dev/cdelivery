O XConfig distribui arquivos de configuração para várias instâncias de serviço, sem integrar um SDK nem manter um serviço separado de configuração.

1. Crie uma aplicação ou abra sua página de configuração.
2. Adicione um arquivo de configuração na seção de arquivos e armazenamento.
3. Envie o arquivo e informe seu caminho absoluto dentro do contêiner, como `/etc/app/config.conf`.
4. Confirme a criação ou atualização para montar o arquivo quando o contêiner iniciar.
5. Para alterar o arquivo depois, envie um substituto e atualize a aplicação. Você também pode baixar o arquivo atual.

XConfig e volumes de dados locais não podem ser usados na mesma aplicação.
