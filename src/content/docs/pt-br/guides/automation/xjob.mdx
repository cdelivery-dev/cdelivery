Use o XJob para executar comandos de aplicações conforme um agendamento ou iniciar uma tarefa manualmente.

1. Abra a página **XJob** de uma aplicação e crie uma tarefa com nome e comando.
2. Escolha um intervalo ou um agendamento por calendário; no calendário, defina os dias, os horários e o fuso horário.
3. Crie a tarefa. Na página de detalhes, use **Executar agora** para iniciá-la manualmente.
4. Consulte o resultado mais recente e a próxima execução nos detalhes; em caso de falha, o erro é exibido.

Os comandos são executados em um novo contêiner com a imagem da aplicação.
