管理 CDelivery 平台及应用所使用的资源。

## 基本管理

1. 从服务器列表打开一台服务器，查看状态、资源与指标。
2. 管理员可在设置中的用户管理里创建账户并分配角色。
3. 打开自己的账户页面，修改密码、设置两步验证或管理 API 密钥。
4. 在设置中的 CDelivery 页面查看版本、更新平台或设置平台域名。

Reader 可查看共享信息，Operator 还可管理应用运维操作，Admin 可管理平台设置与账户。
