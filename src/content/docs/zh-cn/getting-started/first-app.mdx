从容器镜像开始，将应用部署到你自己的服务器。

## 部署

1. 在控制台创建或进入一个分组，选择创建应用。
2. 填写名称和提供 HTTP 服务的应用镜像，先使用一个副本。
3. 在“端口与域名”中添加 TCP 端口映射，填写应用的容器内端口与一个未占用的对外端口。
4. 创建应用，在“概览”中查看容器运行状态。
5. 在浏览器打开 `http://服务器IP:对外端口`，使用实际服务器地址和刚设置的对外端口。

容器内端口须与应用实际监听的端口一致，并在防火墙或安全组中允许访问对外端口。
