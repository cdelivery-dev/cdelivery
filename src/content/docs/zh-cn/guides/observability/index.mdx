Insight 自动采集服务器与应用的指标和日志，无需接入 SDK。

## 查看运行数据

1. 打开 **Insight**，选择服务器和存储后启用。存储支持本地硬盘与 S3 等对象存储。
2. 打开应用的「日志」页面，选择来源和时间范围，搜索相关记录。
3. 在应用或服务器的「指标」页面查看资源使用情况。
4. 结合「事件」中的变更记录，查看同一时间段的日志与指标。

访问记录来自经过 Pingress 的请求。
