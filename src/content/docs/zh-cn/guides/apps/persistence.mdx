将应用数据保存在服务器的本地数据卷中。

1. 打开目标服务器的「数据卷」，创建一个数据卷。
2. 创建应用，在「文件与存储」中选择「数据」及目标服务器。
3. 添加数据卷，填写应用保存数据的容器内路径，例如 `/data`。
4. 创建应用，确认应用使用所挂载的目录。

应用固定在所选服务器、运行一个副本，不能使用 XConfig 或 Guardian。删除应用会保留卷数据。
