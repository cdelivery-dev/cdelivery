将 IM 渠道接入 CDelivery，用于对话与运维通知。

1. 管理员打开**设置 → 渠道**，选择 Slack、Telegram、Discord、Lark 或飞书。
2. 按页面要求填写 Bot 或应用凭据并保存。
3. 在**账户**中打开同一渠道，按提示填写并绑定自己的不可变用户 ID。
4. 配置 [AI 运维助手](/docs/zh-cn/guides/automation/)后，私信 Bot 即可开始对话。
5. 按需在账户的渠道页面开启通知；通知语言在**设置 → Agent → 值班**中设置。

账户绑定与通知设置相互独立。
