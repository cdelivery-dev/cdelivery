CDelivery 汇聚运行指标、应用日志、访问记录与操作事件，让 AI 结合运行上下文分析问题、辅助诊断。

1. 管理员打开**设置 → Agent → 模型**，选择提供商，填写凭据和模型并保存。
2. 配置 [IM 渠道](/docs/zh-cn/guides/automation/im/)，并绑定自己的账户。
3. 向 Bot 发送消息，查询应用状态，或执行权限允许的操作。
4. 需要主动巡查和提醒时，在 **Agent → 值班**中启用值班，设置间隔、策略、语言和角色。

值班 Agent 可在所选角色权限内无需人工确认地执行操作。
