使用 XJob 定时执行应用命令，或手动启动任务。

1. 打开应用的 **XJob** 页面，创建任务并填写名称和命令。
2. 选择按间隔或日历计划执行；日历计划需设置日期、时间和时区。
3. 创建后，可在任务详情中点击**立即运行**，手动启动一次。
4. 在详情中查看最近执行结果和下次运行时间；执行失败时会显示错误。

命令使用应用镜像在独立容器中执行。
