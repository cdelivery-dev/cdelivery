Guardian 在隔离环境中使用 XHealth 验证候选版本，通过后再发布。

## 启用发布验证

1. 为应用配置 [XHealth](/docs/zh-cn/guides/release-safety/xhealth/)，确认检查能够通过。
2. 在应用的 **XHealth** 页面勾选「开启更新保护」并保存。
3. 更新镜像、启动设置或 XConfig 文件，在应用概览中查看部署、验证和发布进度。
4. 验证失败时，查看日志和检查配置，再重试或取消更新。

使用本地数据卷的应用不能启用 Guardian。
