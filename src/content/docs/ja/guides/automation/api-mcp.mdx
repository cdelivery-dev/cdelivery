REST API または MCP を通じて外部ツールを CDelivery に接続します。

1. **アカウント → MCP / API キー**を開き、名前、ロール、必要に応じて有効期限を設定してキーを作成します。
2. 一度だけ表示されるキーをコピーし、`Authorization: Bearer YOUR_API_KEY` として送信します。
3. REST は `GET /api/me` で試せます。ブラウザーで `/scalar` を開くと API ドキュメントを確認できます。
4. MCP は自分のインスタンスの `/mcp` に接続し、同じ Bearer 認証を設定します。

各パスは自分が設置した CDelivery の URL に続けます。キーの権限は所有者の現在のロールを超えません。
