CDelivery は稼働メトリクス、アプリのログ、アクセス記録、操作イベントを集約し、AI が運用状況を踏まえて問題を分析し、診断を支援できるようにします。

1. 管理者として**設定 → Agent → モデル**を開き、プロバイダーを選択して認証情報とモデルを入力し、保存します。
2. [メッセージング連携](/docs/ja/guides/automation/im/)を設定し、自分のアカウントを紐付けます。
3. Bot にメッセージを送り、アプリの状態を質問したり、権限内の操作を依頼したりします。
4. 自動での確認と通知が必要な場合は、**Agent → 自動運用**を有効にし、間隔、方針、言語、ロールを設定します。

自動運用では、選択したロールの権限内で確認なしに操作を実行できます。
