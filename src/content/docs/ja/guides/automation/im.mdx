メッセージングチャネルを CDelivery に接続し、会話や運用通知に使用します。

1. 管理者として**設定 → 連携先**を開き、Slack、Telegram、Discord、Lark、Feishu から選択します。
2. ページの案内に従って Bot またはアプリの認証情報を入力し、保存します。
3. **アカウント**で同じ連携先を開き、案内に従って自分の変更されないユーザー ID を紐付けます。
4. [AI 運用アシスタント](/docs/ja/guides/automation/)を設定したら、Bot にダイレクトメッセージを送って会話を始めます。
5. 必要に応じてアカウントの連携先ページで通知を有効にします。通知の言語は**設定 → Agent → 自動運用**で選択します。

アカウントの紐付けと通知は別々に設定します。
