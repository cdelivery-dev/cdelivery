Insight は SDK なしで、サーバーとアプリケーションのメトリクス・ログを自動収集します。

## 稼働データを確認する

1. **Insight** を開き、サーバーと保存先を選んで有効にします。保存先にはローカルディスクや S3 などのオブジェクトストレージを使えます。
2. アプリケーションの「ログ」でソースと期間を選び、関連する記録を検索します。
3. アプリケーションやサーバーの「メトリクス」でリソース使用状況を確認します。
4. 「イベント」の変更記録と、同じ期間のログ・メトリクスを照らし合わせます。

アクセス記録は Pingress を経由するリクエストが対象です。
