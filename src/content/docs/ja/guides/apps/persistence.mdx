アプリケーションデータをサーバー上のローカルボリュームに保存します。

1. 対象サーバーのボリュームページを開き、ボリュームを作成します。
2. アプリケーションを作成し、ファイルとストレージの項目でデータと対象サーバーを選択します。
3. ボリュームを追加し、`/data` など、アプリケーションがデータを保存するコンテナ内のパスを入力します。
4. アプリケーションを作成し、マウントしたディレクトリが使われていることを確認します。

アプリケーションは選択したサーバー上で1個のレプリカを実行し、XConfig や Guardian は利用できません。アプリケーションを削除してもボリュームのデータは保持されます。
