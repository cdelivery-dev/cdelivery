アプリケーションのイメージ、実行設定、更新を一か所で管理します。

1. アプリケーションを開き、設定ページに進みます。
2. 必要に応じてイメージ、レプリカ数、起動コマンド、環境変数を変更します。
3. 更新を送信します。
4. 概要ページでコンテナの実行状態を確認します。必要に応じて再起動するか、利用可能な場合はロールバックします。

ローカルボリュームを使うアプリケーションは、選択したサーバー上で1個のレプリカを実行します。
