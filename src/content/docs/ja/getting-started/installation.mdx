CDelivery をインストールし、最初のアプリケーションをデプロイする準備を整えます。

AI にインストールと設定を手伝ってもらうには、[AI 向けインストールガイド（英語）](/install.md)を AI ツールに共有してください。

## インストール

サーバーのターミナルで、公式サイトのインストールコマンドを実行します。

```sh
curl -fsSL https://cdelivery.dev/install.sh | sh
```

対応する Linux ディストリビューションでは、Docker と必要なツールが未導入の場合、インストーラーが準備します。それ以外の Linux 環境では、事前に Docker と `jq` を利用できる状態にしてください。既存の Docker はそのまま使用します。

macOS では、先に OrbStack または Docker Desktop を起動してください。Homebrew を使用する場合、次のコマンドで OrbStack を準備できます。

```sh
brew install --cask orbstack
orb start
```

必要に応じてインストーラーがこれらの手順を案内します。デスクトップアプリのインストールや起動を自動では行いません。

## サーバー間の通信アドレスを選ぶ

Linux と macOS で初めてインストールする際は、適切な IPv4 アドレスが一つだけでも、必ず番号で選択します。プライベートアドレスが先に表示され、サーバー一台だけの構成用の `127.0.0.1` も常に候補に含まれます。

ほかのサーバーから到達できる固定のアドレスを選んでください。選択メニューを省略して直接指定する場合や、対話端末がない場合は、次のコマンドを使います。

```sh
curl -fsSL https://cdelivery.dev/install.sh | sh -s -- --advertise-addr 192.168.1.10
```

例のアドレスを使用する IPv4 アドレスに置き換えてください。ネットワークインターフェース名は指定できません。通信アドレスとダッシュボードのアドレスは異なっていても構いません。既存のインストールでは現在の通信アドレスを維持します。

## ダッシュボードを開く

1. インストール後、ブラウザーで `http://SERVER_IP:9000` を開きます。`SERVER_IP` はサーバーの IP アドレスに置き換えてください。macOS では `http://localhost:9000` を使用します。ターミナルにもダッシュボードのアクセス先が表示されます。
2. 氏名、メールアドレス、パスワードを入力し、最初の管理者アカウントを作成します。
3. 初期化の完了を待ち、作成したアカウントでログインします。

サーバーのファイアウォールまたはセキュリティグループで、ポート `9000` へのアクセスを許可してください。
