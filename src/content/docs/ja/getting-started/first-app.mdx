コンテナイメージから、自分のサーバーにアプリケーションをデプロイします。

## デプロイ

1. ダッシュボードでグループを作成するか既存のグループを開き、アプリケーションの作成を選びます。
2. 名前と HTTP サービスを提供するアプリケーションのイメージを入力し、レプリカ数を 1 にします。
3. ポートとドメインの設定で TCP ポートの割り当てを追加し、コンテナ内のポートと未使用の公開ポートを入力します。
4. アプリケーションを作成し、概要ページでコンテナの稼働状態を確認します。
5. ブラウザーで `http://SERVER_IP:PUBLIC_PORT` を開きます。サーバーの IP アドレスと設定した公開ポートに置き換えてください。

コンテナ内のポートはアプリケーションが待ち受けるポートと一致させ、ファイアウォールまたはセキュリティグループで公開ポートへのアクセスを許可してください。
