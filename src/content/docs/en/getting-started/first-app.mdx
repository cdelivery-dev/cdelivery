Deploy an application from a container image to your own server.

## Deploy

1. Create or open a group in the dashboard, then choose to create an application.
2. Enter a name and the image of an HTTP application. Start with one replica.
3. Under ports and domains, add a TCP port mapping with the application's container port and an unused public port.
4. Create the application and check its container state on the overview page.
5. Open `http://SERVER_IP:PUBLIC_PORT` in your browser, using your server's IP address and the public port you chose.

The container port must match the port the application listens on. Allow access to the public port in your firewall or security group.
