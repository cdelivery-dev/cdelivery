CDelivery is a self-hosted operations platform for deploying applications, managing domains and HTTPS, scheduling tasks, and viewing logs and metrics.

## What you can do

- Organize applications into groups, deploy container images, and distribute configuration files with XConfig.
- Route requests to applications through Pingress and automatically manage HTTPS certificates.
- Check business workflows with XHealth; enable Guardian to validate new versions before release.
- Collect application logs, access records, and server metrics with Insight, without an SDK.
- Schedule routine commands with XJob and use the AI assistant to help diagnose problems.

Start with one server, then add resources as your applications grow.
