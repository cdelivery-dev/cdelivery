Set up CDelivery and prepare the platform for your first application.

For help with installation and configuration, share the [AI installation guide](/install.md) with your AI tool.

## Install

Run the command from the CDelivery homepage in your server's terminal:

```sh
curl -fsSL https://cdelivery.dev/install.sh | sh
```

On supported Linux distributions, the installer prepares Docker and required tools when they are missing. Other Linux distributions require an already working Docker installation and `jq`. Existing Docker installations are reused.

On macOS, start OrbStack or Docker Desktop before running the command. If you use Homebrew, you can prepare OrbStack with:

```sh
brew install --cask orbstack
orb start
```

The installer shows these steps when needed; it does not install or start a desktop application automatically.

## Choose the server communication address

On a fresh installation on Linux or macOS, the installer always asks you to choose an IPv4 address by number, even if only one suitable address is available. Private addresses are listed first, and `127.0.0.1` is always offered for a single-server installation.

Use a stable address that your other servers can reach. To skip the menu and specify the address directly, or when no interactive terminal is available:

```sh
curl -fsSL https://cdelivery.dev/install.sh | sh -s -- --advertise-addr 192.168.1.10
```

Replace the example with the intended IPv4 address. Interface names are not accepted. The server communication address can differ from the dashboard address. Existing installations retain their current communication address.

## Open the dashboard

1. After installation, open `http://SERVER_IP:9000` in your browser, replacing `SERVER_IP` with your server's IP address. On macOS, use `http://localhost:9000`. The terminal also prints the dashboard address.
2. Enter your name, email address, and password to create the first administrator account.
3. Wait for initialization to finish, then sign in with that account.

Allow access to port `9000` in your server's firewall or security group.
