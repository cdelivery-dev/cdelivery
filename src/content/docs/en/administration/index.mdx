Manage the CDelivery installation and the resources used by your applications.

## Basic management

1. Select a server from the server list to view its state, resources, and metrics.
2. As an administrator, open user management in settings to create accounts and assign roles.
3. Open your account page to change your password, configure two-factor authentication, or manage API keys.
4. Open CDelivery in settings to view the platform version, update it, or configure its domain.

Reader can view shared information, Operator can also manage application operations, and Admin manages platform settings and accounts.
