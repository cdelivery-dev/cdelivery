Guardian uses XHealth to validate a candidate version in an isolated environment before release.

## Enable release validation

1. Configure [XHealth](/docs/guides/release-safety/xhealth/) for the application and confirm that its checks pass.
2. On the application's XHealth tab, select **Enable Upgrade Guardian** and save.
3. Update the image, startup settings, or XConfig files. Follow deployment, validation, and release progress on the application overview.
4. If validation fails, inspect the logs and check configuration, then retry or cancel the update.

Applications using local data volumes cannot enable Guardian.
