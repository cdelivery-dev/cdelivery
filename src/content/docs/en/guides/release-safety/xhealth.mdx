XHealth runs periodic checks to verify application behavior, including critical business flows such as user login.

## Create a check

1. Open the application's **XHealth** tab.
2. Upload a Hurl file or enter a custom test command.
3. Select the test target and interval, then enable the check.
4. Review the latest status and any error message on the XHealth tab. Use the application logs to help investigate failures.

Enable Guardian to use these checks for release validation as well.
