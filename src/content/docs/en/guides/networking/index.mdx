Pingress routes requests to your application and manages HTTPS certificates.

1. Enable Pingress and choose the server or servers where it will run.
2. Point the domain's DNS records to the addresses that reach Pingress.
3. In the application's ports and domains settings, add the domain and the port the application listens on inside the container. Enable HTTPS if needed, then save the application settings.
4. If using HTTPS, enable automatic certificates or upload a certificate on the Pingress certificates page.
5. Visit the domain to check access.

Make sure DNS resolves correctly and the HTTP/HTTPS ports are reachable. Automatic certificates are issued and renewed in the background.
