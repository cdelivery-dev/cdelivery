Insight automatically collects server and application metrics and logs, without an SDK.

## View runtime data

1. Open **Insight**, select a server and storage, and enable collection. Storage can be local disk or an object store such as S3.
2. Open the application's **Logs** tab. Select a source and time range, then search for the relevant messages.
3. Open **Metrics** on an application or server to view resource usage.
4. Check **Events** to correlate changes with logs and metrics from the same period.

Access records cover requests routed through Pingress.
