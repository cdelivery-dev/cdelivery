CDelivery brings together metrics, application logs, access records, and operation events to help AI analyze issues and assist with diagnosis.

1. As an administrator, open **Settings → Agent → Model**, choose a provider, enter its credentials and model, and save.
2. Set up a [messaging channel](/docs/guides/automation/im/) and bind your account.
3. Message the bot to ask about application status or request an operation within your permissions.
4. For proactive checks and notifications, open **Agent → Duty**, enable it, and set the interval, policy, language, and role.

Duty can act within the selected role without manual confirmation.
