Use XJob to run application commands on a schedule or start a task manually.

1. Open an application, go to **XJob**, and create a task with a name and command.
2. Choose an interval or a calendar schedule; for calendar schedules, set the days, times, and time zone.
3. Create the task. Use **Run now** on its detail page to start it manually.
4. Check the latest result and next run time on the detail page; failed runs show an error.

Commands run in a fresh container using the application's image.
