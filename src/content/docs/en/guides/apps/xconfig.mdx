XConfig distributes configuration files to multiple service instances without an SDK or a separate configuration service.

1. Create an application or open its configuration page.
2. Add a configuration file under files and storage.
3. Upload the file and enter its absolute path inside the container, such as `/etc/app/config.conf`.
4. Submit the creation or update to mount the file when the container starts.
5. To change the file later, upload a replacement and update the application. You can also download the current file.

XConfig and local data volumes cannot be used in the same application.
