Keep application data in a local volume on a server.

1. Open the target server's volumes page and create a volume.
2. Create an application, select data under files and storage, and choose that server.
3. Add the volume and enter the container path where the application stores its data, such as `/data`.
4. Create the application and confirm that it uses the mounted directory.

The application runs one replica on the selected server and cannot use XConfig or Guardian. Deleting the application keeps the volume data.
