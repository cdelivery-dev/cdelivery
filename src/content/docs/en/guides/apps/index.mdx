Manage application images, runtime settings, and updates in one place.

1. Open an application and go to its configuration page.
2. Change the image, replica count, startup command, or environment variables as needed.
3. Submit the update.
4. Check the running containers in the overview. Use restart or, when available, rollback as needed.

Applications with local data volumes run a single replica on the selected server.
