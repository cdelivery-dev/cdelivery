Usa XJob para ejecutar comandos de aplicaciones según una programación o iniciar una tarea manualmente.

1. Abre la página **XJob** de una aplicación y crea una tarea con un nombre y un comando.
2. Elige un intervalo o una programación por calendario; para el calendario, indica los días, las horas y la zona horaria.
3. Crea la tarea. En su página de detalles, pulsa **Ejecutar ahora** para iniciarla manualmente.
4. Consulta el último resultado y la próxima ejecución en los detalles; si falla, se muestra el error.

Los comandos se ejecutan en un contenedor nuevo con la imagen de la aplicación.
