Conecta herramientas externas a CDelivery mediante la API REST o MCP.

1. Abre **Cuenta → MCP / Claves de API** y crea una clave con nombre, rol y fecha de caducidad opcional.
2. Copia la clave, que se muestra una sola vez, y envíala como `Authorization: Bearer YOUR_API_KEY`.
3. Para REST, prueba `GET /api/me` y abre `/scalar` en el navegador para consultar la documentación de la API.
4. Para MCP, usa la dirección `/mcp` de tu instancia y la misma autenticación Bearer.

Todas las rutas pertenecen a tu instancia de CDelivery. La clave no puede conceder más acceso que el rol actual de su titular.
