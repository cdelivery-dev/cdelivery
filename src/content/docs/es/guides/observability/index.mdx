Insight recopila automáticamente métricas y registros de servidores y aplicaciones, sin SDK.

## Consultar los datos de ejecución

1. Abre **Insight**, selecciona un servidor y el almacenamiento y activa la recopilación. Puedes usar disco local o almacenamiento de objetos, como S3.
2. En **Registros** de la aplicación, selecciona el origen y el intervalo de tiempo y busca los mensajes relevantes.
3. Abre **Métricas** en una aplicación o servidor para consultar el uso de recursos.
4. Consulta **Eventos** para relacionar los cambios con los registros y las métricas del mismo periodo.

Los registros de acceso corresponden a las solicitudes que pasan por Pingress.
