Gestiona la imagen, los ajustes de ejecución y las actualizaciones de la aplicación en un solo lugar.

1. Abre la aplicación y entra en su página de configuración.
2. Cambia la imagen, el número de réplicas, el comando de inicio o las variables de entorno según lo necesites.
3. Envía la actualización.
4. Revisa el estado de los contenedores en la vista general. Reinicia la aplicación o, cuando esté disponible, revierte el último cambio.

Las aplicaciones con volúmenes de datos locales ejecutan una sola réplica en el servidor seleccionado.
