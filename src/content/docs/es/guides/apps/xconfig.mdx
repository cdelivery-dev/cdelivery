XConfig distribuye archivos de configuración a varias instancias de servicio sin integrar un SDK ni mantener un servicio de configuración adicional.

1. Crea una aplicación o abre su página de configuración.
2. Añade un archivo de configuración en la sección de archivos y almacenamiento.
3. Sube el archivo e indica su ruta absoluta dentro del contenedor, como `/etc/app/config.conf`.
4. Confirma la creación o actualización para montar el archivo al iniciar el contenedor.
5. Para cambiar el archivo después, sube uno nuevo y actualiza la aplicación. También puedes descargar el archivo actual.

XConfig y los volúmenes de datos locales no pueden usarse en la misma aplicación.
