Instala CDelivery y prepara la plataforma para tu primera aplicación.

Para recibir ayuda con la instalación y la configuración, comparte la [guía de instalación para IA (en inglés)](/install.md) con tu herramienta de IA.

## Instalación

Ejecuta el comando de la web de CDelivery en la terminal de tu servidor:

```sh
curl -fsSL https://cdelivery.dev/install.sh | sh
```

En las distribuciones Linux compatibles, el instalador prepara Docker y las herramientas necesarias cuando faltan. En otras distribuciones, Docker y `jq` deben estar disponibles de antemano. Las instalaciones existentes de Docker se reutilizan.

En macOS, inicia OrbStack o Docker Desktop antes de ejecutar el comando. Si usas Homebrew, puedes preparar OrbStack con:

```sh
brew install --cask orbstack
orb start
```

El instalador muestra estos pasos cuando hace falta; no instala ni inicia aplicaciones de escritorio automáticamente.

## Elige la dirección de comunicación entre servidores

En la primera instalación en Linux o macOS, el instalador siempre pide que elijas una dirección IPv4 por su número, aunque solo haya una dirección adecuada. Las direcciones privadas aparecen primero, y `127.0.0.1` siempre está disponible para una instalación con un único servidor.

Usa una dirección estable a la que puedan acceder los demás servidores. Para omitir el menú y especificar la dirección directamente, o cuando no haya una terminal interactiva:

```sh
curl -fsSL https://cdelivery.dev/install.sh | sh -s -- --advertise-addr 192.168.1.10
```

Sustituye el ejemplo por la dirección IPv4 deseada. No se aceptan nombres de interfaces. La dirección de comunicación entre servidores puede ser distinta de la dirección del panel. Las instalaciones existentes conservan su dirección de comunicación actual.

## Abre el panel

1. Tras la instalación, abre `http://SERVER_IP:9000` en el navegador y sustituye `SERVER_IP` por la IP de tu servidor. En macOS, usa `http://localhost:9000`. La terminal también muestra la dirección del panel.
2. Introduce tu nombre, correo electrónico y contraseña para crear la primera cuenta de administrador.
3. Espera a que termine la inicialización e inicia sesión con esa cuenta.

Permite el acceso al puerto `9000` en el cortafuegos o grupo de seguridad de tu servidor.
