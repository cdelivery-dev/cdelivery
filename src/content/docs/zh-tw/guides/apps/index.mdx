在同一處管理應用程式映像檔、執行設定與後續更新。

1. 進入應用程式，開啟設定頁面。
2. 依需要修改映像檔、副本數、啟動指令或環境變數。
3. 提交更新。
4. 在概覽中查看容器執行狀態，依需要重新啟動，或在可用時回復上次修改。

使用本機資料卷的應用程式固定在所選伺服器，執行一個副本。
