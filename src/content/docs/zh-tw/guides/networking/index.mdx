Pingress 將使用者請求導向應用程式，並管理 HTTPS 憑證。

1. 啟用 Pingress，選擇執行它的伺服器。
2. 將網域的 DNS 記錄指向可存取 Pingress 的位址。
3. 在應用程式的連接埠與網域設定中新增網域，填寫應用程式實際監聽的容器內連接埠，依需要啟用 HTTPS，然後儲存應用程式設定。
4. 使用 HTTPS 時，在 Pingress 的憑證頁面啟用自動憑證或上傳憑證。
5. 開啟網域，確認應用程式可用。

請確保網域解析正確，且 HTTP/HTTPS 連接埠可連線。自動憑證會在背景簽發及更新。
