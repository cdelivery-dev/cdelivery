Insight 自動收集伺服器與應用程式的指標和日誌，不必導入 SDK。

## 檢視執行資料

1. 開啟 **Insight**，選擇伺服器與儲存方式後啟用。儲存支援本機硬碟與 S3 等物件儲存。
2. 開啟應用程式的「日誌」頁面，選擇來源與時間範圍，搜尋相關記錄。
3. 在應用程式或伺服器的「指標」頁面檢視資源使用情況。
4. 結合「事件」中的變更記錄，檢視同一時段的日誌與指標。

存取記錄來自經過 Pingress 的請求。
