將 IM 管道連接到 CDelivery，用於對話與維運通知。

1. 管理員開啟**設定 → 管道**，選擇 Slack、Telegram、Discord、Lark 或飛書。
2. 依頁面要求填寫 Bot 或應用程式驗證資訊並儲存。
3. 在**帳戶**中開啟相同管道，依提示填寫並綁定自己的固定使用者 ID。
4. 設定 [AI 維運助手](/docs/zh-tw/guides/automation/)後，私訊 Bot 即可開始對話。
5. 視需要在帳戶的管道頁面開啟通知；通知語言在**設定 → Agent → 值班**中設定。

帳戶綁定與通知設定彼此獨立。
