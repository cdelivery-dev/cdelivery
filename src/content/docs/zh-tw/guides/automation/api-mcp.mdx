透過 REST API 或 MCP 將外部工具連接到 CDelivery。

1. 開啟**帳戶 → MCP / API 金鑰**，填寫名稱、選擇角色，視需要設定有效期限並建立。
2. 複製僅顯示一次的金鑰，請求時使用 `Authorization: Bearer YOUR_API_KEY`。
3. REST 可從 `GET /api/me` 開始；在瀏覽器開啟 `/scalar` 查看 API 文件。
4. MCP 使用目前實例的 `/mcp` 位址，並設定相同的 Bearer 驗證。

以上路徑均位於你部署的 CDelivery 位址下；金鑰權限不會超過所屬使用者目前的角色。
