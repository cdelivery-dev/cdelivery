使用 XJob 定時執行應用程式指令，或手動啟動工作。

1. 開啟應用程式的 **XJob** 頁面，建立工作並填寫名稱和指令。
2. 選擇依間隔或日曆排程執行；日曆排程需設定日期、時間和時區。
3. 建立後，可在工作詳情中點選**立即執行**，手動啟動一次。
4. 在詳情中檢視最近執行結果和下次執行時間；執行失敗時會顯示錯誤。

指令使用應用程式映像檔，在獨立容器中執行。
