CDelivery 匯整執行指標、應用程式日誌、存取紀錄與操作事件，讓 AI 結合執行環境的脈絡分析問題、輔助診斷。

1. 管理員開啟**設定 → Agent → 模型**，選擇供應商，填寫驗證資訊和模型並儲存。
2. 設定 [IM 管道](/docs/zh-tw/guides/automation/im/)，並綁定自己的帳戶。
3. 傳送訊息給 Bot，查詢應用程式狀態，或執行權限允許的操作。
4. 需要主動巡查和提醒時，在 **Agent → 值班**中啟用值班，設定間隔、策略、語言和角色。

值班 Agent 可在所選角色權限內執行操作，無須人工確認。
