從容器映像檔開始，將應用程式部署到自己的伺服器。

## 部署

1. 在控制台建立或進入一個分組，選擇建立應用程式。
2. 填寫名稱與提供 HTTP 服務的應用程式映像檔，先使用一個副本。
3. 在「連接埠與網域」中新增 TCP 連接埠對應，填寫應用程式的容器內連接埠與一個未使用的對外連接埠。
4. 建立應用程式，在「概覽」中查看容器執行狀態。
5. 在瀏覽器開啟 `http://伺服器IP:對外連接埠`，使用實際伺服器位址與剛設定的對外連接埠。

容器內連接埠須與應用程式實際監聽的連接埠一致，並在防火牆或安全群組中允許存取對外連接埠。
