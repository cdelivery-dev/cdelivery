CDelivery 是自架式維運平台，協助你部署應用程式、管理網域與 HTTPS、安排排程工作，並查看日誌與指標。

## 可以做什麼

- 用分組組織應用程式，從容器映像檔部署服務，透過 XConfig 分發設定檔。
- 透過 Pingress 將請求路由至應用程式，並自動管理 HTTPS 憑證。
- 用 XHealth 檢查關鍵業務流程；啟用 Guardian 後，新版本通過驗證才發布。
- 用 Insight 彙整應用程式日誌、存取記錄與伺服器指標，無需整合 SDK。
- 用 XJob 定時執行日常命令，透過 AI 助手協助分析與診斷問題。

一台伺服器即可開始使用，再依業務需求擴充資源。
