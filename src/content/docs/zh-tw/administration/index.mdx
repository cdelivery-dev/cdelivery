管理 CDelivery 平台及應用程式所使用的資源。

## 基本管理

1. 從伺服器清單開啟一台伺服器，查看狀態、資源與指標。
2. 管理員可在設定中的使用者管理建立帳戶並分配角色。
3. 開啟自己的帳戶頁面，變更密碼、設定兩步驟驗證或管理 API 金鑰。
4. 在設定中的 CDelivery 頁面查看版本、更新平台或設定平台網域。

Reader 可查看共用資訊，Operator 也可管理應用程式維運操作，Admin 可管理平台設定與帳戶。
