Richte CDelivery ein und bereite die Plattform auf deine erste Anwendung vor.

Für Hilfe bei der Installation und Einrichtung teile die [Installationsanleitung für KI (auf Englisch)](/install.md) mit deinem KI-Tool.

## Installation

Führe den Installationsbefehl von der CDelivery-Website im Terminal deines Servers aus:

```sh
curl -fsSL https://cdelivery.dev/install.sh | sh
```

Auf unterstützten Linux-Distributionen richtet das Installationsskript Docker und benötigte Werkzeuge ein, wenn sie fehlen. Auf anderen Distributionen müssen Docker und `jq` bereits verfügbar sein. Vorhandene Docker-Installationen werden weiterverwendet.

Starte unter macOS zunächst OrbStack oder Docker Desktop. Wenn du Homebrew verwendest, kannst du OrbStack so vorbereiten:

```sh
brew install --cask orbstack
orb start
```

Das Installationsskript zeigt diese Schritte bei Bedarf an. Es installiert oder startet keine Desktop-Anwendung automatisch.

## Adresse für die Serverkommunikation wählen

Bei der ersten Installation unter Linux oder macOS wählst du die IPv4-Adresse immer über ihre Nummer aus, auch wenn nur eine geeignete Adresse vorhanden ist. Private Adressen stehen zuerst; `127.0.0.1` wird immer für eine Installation auf einem einzelnen Server angeboten.

Verwende eine stabile Adresse, die deine anderen Server erreichen können. Mit folgendem Befehl überspringst du das Menü und gibst die Adresse direkt an, auch wenn kein interaktives Terminal verfügbar ist:

```sh
curl -fsSL https://cdelivery.dev/install.sh | sh -s -- --advertise-addr 192.168.1.10
```

Ersetze das Beispiel durch die gewünschte IPv4-Adresse. Namen von Netzwerkschnittstellen werden nicht akzeptiert. Die Adresse für die Serverkommunikation kann von der Dashboard-Adresse abweichen. Bestehende Installationen behalten ihre aktuelle Kommunikationsadresse.

## Dashboard öffnen

1. Öffne nach der Installation `http://SERVER_IP:9000` im Browser. Ersetze `SERVER_IP` durch die IP-Adresse deines Servers. Unter macOS verwendest du `http://localhost:9000`. Die Dashboard-Adresse wird auch im Terminal ausgegeben.
2. Gib deinen Namen, deine E-Mail-Adresse und ein Passwort ein, um das erste Administratorkonto zu erstellen.
3. Warte, bis die Initialisierung abgeschlossen ist, und melde dich mit diesem Konto an.

Erlaube den Zugriff auf Port `9000` in der Firewall oder Sicherheitsgruppe deines Servers.
