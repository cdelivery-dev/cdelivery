CDelivery führt Laufzeitmetriken, Anwendungslogs, Zugriffsprotokolle und Betriebsereignisse zusammen, damit die KI Probleme im Zusammenhang analysieren und die Diagnose unterstützen kann.

1. Öffne als Administrator **Einstellungen → Agent → Modell**, wähle einen Anbieter, gib Zugangsdaten und Modell ein und speichere.
2. Richte einen [Messaging-Kanal](/docs/de/guides/automation/im/) ein und verknüpfe dein Konto.
3. Sende dem Bot eine Nachricht, um den Anwendungsstatus abzufragen oder eine Aktion innerhalb deiner Berechtigungen anzufordern.
4. Für proaktive Prüfungen und Benachrichtigungen aktiviere **Agent → Bereitschaftsdienst** und lege Intervall, Strategie, Sprache und Rolle fest.

Der Bereitschaftsdienst kann innerhalb der gewählten Rolle ohne manuelle Bestätigung handeln.
