CDelivery is an operations platform for deploying container images and maintaining applications. Start with one server, then add capacity when your workloads require it.

## Get started

1. [Before installation](/docs/getting-started/requirements/): Prepare server addresses, networking, and console access.
2. [Install CDelivery](/docs/getting-started/installation/): Start the platform and create an administrator.
3. [Deploy your first application](/docs/getting-started/first-app/): Deploy Hello and verify access.

## Core concepts

| Object | Purpose |
| --- | --- |
| Server | Provides compute resources and local storage. |
| Group | Organizes applications and provides a shared network. |
| Application | Combines a container image, configuration, and desired runtime settings. |
| Replica | A running instance of an application. |

Groups do not isolate account permissions; see [roles and permissions](/docs/administration/accounts/roles/). For data that must survive container replacement, read [data persistence](/docs/guides/apps/persistence/). Replicas and application rollback do not replace backups.
