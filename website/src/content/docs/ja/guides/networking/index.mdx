内部通信、公開ポート、Pingress の HTTP/HTTPS ルートを区別します。

## 選択

| 用途 | 設定 |
| --- | --- |
| グループ内通信 | アプリ名と内部ポート |
| TCP/UDP の直接接続 | ポート公開 |
| HTTP ドメイン | コンテナポートへのルート |
| HTTPS | ルートと有効な証明書 |

ドメインルートのためにポートを直接公開する必要はありません。

## トラブルシューティング

DNS、接続、TLS、アプリ応答を別々に検証します。証明書取得成功はバックエンド正常の証明ではありません。

[管理画面のドメイン](/docs/ja/administration/platform/access/)は別設定です。
