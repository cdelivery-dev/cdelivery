外部で発行を管理する場合、PEM の証明書チェーンと対応する秘密鍵を登録します。

## 登録

Admin が、対象ホスト名を含み現在有効な証明書、完全なチェーン、一致する鍵を準備します。ドメインを選んで登録し、ルートの HTTPS を確認します。

実クライアントで名前、発行者、チェーン、期限を調べ、IPv6 を含む各入口を確認します。秘密鍵は診断に貼り付けないでください。

登録成功だけでは DNS が正しい入口を指すと確認できません。

## 更新

独自証明書は ACME の更新対象ではありません。期限を管理し、失効前に置換して実際に配信される証明書を確認します。

## 問題の切り分け

接続先の問題と TLS を区別し、名前、有効期間、チェーン、鍵の組を確認します。前段プロキシが別証明書を返す場合もあります。

自動化する場合は[自動証明書](/docs/ja/guides/networking/automatic-certificates/)の検証要件を確認します。
