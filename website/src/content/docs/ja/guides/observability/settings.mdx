Admin が Insight、収集器、保存先、保存期間を設定します。

## 保存先

Local、S3、endpoint 付き S3-compatible、サービスアカウント JSON の GCS、Azure を選びます。保存対象と認証を有効化前に準備します。

有効化後、種類や保存先識別は通常編集で移行できません。認証情報や対応する region は変更可能です。Local は固定サーバーが必要で、移行とバックアップは別途計画します。

## 時間

保持は標準 30 日、範囲 1–3650 日。測定は標準 5 秒、範囲 1–60 秒。flush は標準 3 分。ファイルシステムは 5 分です。

固定サーバーはバッファーを参照できます。ラベルによる分散配置は flush と同期を待つ場合があります。高頻度・長期保存ほど容量が必要です。

## 検証

新しい活動を発生させ、各サーバーのログ・指標・イベントを確認します。過去分の自動取り込みはありません。

欠落はコンポーネント、通信、認証、期間を調べます。保持短縮は履歴を消す場合があります。[ログドライバー](/docs/ja/guides/observability/logs/application/)は別設定です。
