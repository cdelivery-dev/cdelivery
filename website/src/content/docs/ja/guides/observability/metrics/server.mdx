CPU、メモリー、ネットワーク、ファイルシステムからホストの負荷を判断します。

## 範囲

物理ネットワークインターフェースと、ローカルの書き込み可能なブロックデバイス上のファイルシステムを扱います。すべての仮想機器や個別ボリューム一覧ではありません。

サーバー指標は標準で 5 秒ごとに収集します。ファイルシステムの測定間隔は 5 分で固定され、通常の測定間隔とは独立しています。

## 調査

CPU はアプリとレプリカ、メモリーは上限と終了、ディスクはログと業務データ、通信はリクエストと比較します。

報告不足ではサーバー、収集器、通信、Insight を確認します。

## 確認

時刻と単位を確認し、空き容量を増やした後は次のディスク測定を待ちます。欠測はゼロではありません。

ホスト空き容量と個別サイズは別です。[ボリューム](/docs/ja/administration/nodes/volumes/)、[アプリ指標](/docs/ja/guides/observability/metrics/application/)、[収集](/docs/ja/guides/observability/settings/)を参照します。
