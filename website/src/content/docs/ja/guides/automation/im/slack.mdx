Socket Mode を使用し、公開イベント受信 URL は不要です。

## アプリ作成

<Steps>

1. [Slack](https://api.slack.com/apps) でアプリを作成します。
2. `chat:write`、`im:write`、`im:history` を付与します。
3. Socket Mode を有効化し、`connections:write` を持つ app token を作成します。
4. `message.im` を購読し、App Home のメッセージ送信を許可します。
5. アプリをインストールします。

</Steps>

Admin が `xoxb-` bot token と `xapp-` app token を保存します。メンションには `app_mentions:read` と `app_mention`、プロフィールには `users:read` が必要です。権限変更後は再承認・インストールします。[公式手順](https://docs.slack.dev/tools/java-slack-sdk/guides/socket-mode/)も参照してください。

## 紐付け

本人の Member ID をアカウントに入力します。新しい紐付けは既定で通知を受け取り、後から無効にできます。チャネル、app、bot ID は使いません。[モデル](/docs/ja/guides/automation/models/)設定後、個別メッセージで読み取りを試します。

## 調査

トークンの組、インストール、イベント、権限、App Home、通信を確認します。プロフィール取得と配信の問題は別です。他人の ID は自分の権限を渡し得るため、本人確認を行ってください。
