現在または直近の実行と次回日時を表示し、無制限の履歴一覧ではありません。

API フィールド `last_run` は観測できた最新タスクの作成時刻で、終了時刻ではありません。記録の欠如は成功を示しません。タイムアウトによる停止は `XJobFailed` イベントに記録されます。実行記録が消えている場合はイベントとログを確認してください。

## 読み方

名前、状態、時刻、結果を確認し、対応する XJob ログを選びます。Pending は未完了、Running は成功前です。終了 0 が業務結果を示す必要があります。

## 調査

起動なしはサーバー・資源・イメージ、コマンドなしはツール・パス、接続失敗はグループ・ホスト・ポート・認証、超過は依存先・時間制限、ログなしはソース・期間・ドライバーを確認します。

別コンテナーのため、業務側一時ファイルは自動で引き継ぎません。

## 再試行

前の実行が部分的に処理したか確認します。失敗は書き込みや外部要求を自動で取り消しません。

コマンドや[予定](/docs/ja/guides/automation/xjob/schedule/)変更後は新しい実行と次回日時を検証します。完全な業務履歴が必要なら業務システム側に残します。
