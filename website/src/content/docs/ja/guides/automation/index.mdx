AI はプラットフォーム権限に従って情報を読み、ツールを実行します。

## 利用形態

会話には[モデル](/docs/ja/guides/automation/models/)、[チャネル](/docs/ja/guides/automation/im/)、本人の紐付けが必要です。[自動当番](/docs/ja/guides/automation/duty/)はイベント分析と定期巡回を行います。外部クライアントは [MCP](/docs/ja/guides/automation/api-mcp/) を使い、通常通知にはモデルは不要です。

Admin がモデルと当番を設定します。会話は現在のユーザー権限、当番は独自の役割で標準 Reader、個人アカウント操作はありません。

## 検証

本人 ID を登録し、読み取り質問から始めて対象と権限を確認します。書き込み役割は無人変更を可能にし、通知が毎回の事前承認になるわけではありません。

## データと障害

外部モデルには必要な会話・運用コンテキストが送られます。扱うデータに適した提供元を選びます。

配信、モデル接続、ツール対応を分けて調べます。一覧にあるモデルが必要機能を持つとは限りません。回答文だけでなく実結果を確認します。
