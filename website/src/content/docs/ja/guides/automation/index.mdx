XJob で定期タスクを実行し、メッセージチャネルで通知を受け取ります。必要に応じて AI や外部クライアントを API と MCP で接続します。

## タスクと通知

<CardGrid>

<Card title="スケジュールタスク" href="/docs/ja/guides/automation/xjob/" icon="ph:clock">
  XJob タスクを作成し、スケジュールと結果を確認します。
</Card>

<Card title="メッセージと通知" href="/docs/ja/guides/automation/im/" icon="ph:chat-circle">
  チャネルを接続し、本人 ID と通知設定を登録します。
</Card>

</CardGrid>

## AI と外部ツール

<CardGrid>

<Card title="AI アシスタントを使う" href="/docs/ja/guides/automation/assistant/" icon="ph:chat-circle-dots">
  メッセージチャネルから運用状況を調べ、アカウントの権限内で実行された操作を確認します。
</Card>

<Card title="モデル設定" href="/docs/ja/guides/automation/models/" icon="ph:cpu">
  提供元、認証情報、ツールに対応するモデルを設定します。
</Card>

<Card title="AI 自動運用" href="/docs/ja/guides/automation/duty/" icon="ph:robot">
  イベント分析、定期確認、自動運用の役割を設定します。
</Card>

<Card title="API と MCP" href="/docs/ja/guides/automation/api-mcp/" icon="ph:code">
  API キーとアカウント権限で外部ツールを接続します。
</Card>

</CardGrid>
