待機、実行、成功、失敗、結果なし終了を区別します。

## 状態

Pending は待機、Running は実行中、Passed は成功、Failed は失敗、Settled は利用できる結果なしで終了した状態です。

Settled を成功と扱いません。Guardian でも結果なしは検証上の問題です。

## 調査

待機はサーバー、資源、イメージ、配置を確認します。長時間実行はタイムアウトと依存先を、失敗は XHealth ログ、アサーション、終了値、ポート、パス、環境、ツールを確認します。

内部 HTTP の失敗は公開証明書の問題とは限りません。内部成功も公開 DNS/TLS の成功を保証しないため別途試します。

## 変更後

新たに実行し、定義と時刻を確認します。過去の緑表示に頼らず、プロセス存在だけでなく業務の利用可能性を検証します。

[設定](/docs/ja/guides/release-safety/xhealth/)や[アプリログ](/docs/ja/guides/observability/logs/application/)を参照してください。
