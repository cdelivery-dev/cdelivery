イメージ参照、バージョン、取得用認証情報を設定します。

## 参照

`nginx:stable-alpine` のようにリポジトリーとタグを指定し、`https://` や Web ページの URL は含めません。現在の入力は `@sha256:` の digest 形式に対応しません。実行先アーキテクチャと版の要件を確認します。

レジストリー上でタグが変わっても自動更新されません。変更なし保存も再配置しないため、必要なら[再起動](/docs/ja/guides/apps/lifecycle/)します。

## 非公開レジストリー

コンソールはユーザー名を指定するとパスワードも要求します。既存情報を変えない場合は不要な編集を取り消し、変更時は必要な組を入力します。

API で秘密を省略して保持できるのは対象範囲が同じ場合です。レジストリー変更時は適切な認証情報が必要で、保存済みパスワードは返されません。

## 調査

未存在は名前・タグ、認証失敗はトークン・権限、タイムアウトは DNS・通信、非互換はアーキテクチャを確認します。取得後も終了する場合はコマンド、環境、マウントを確認します。

版、ログ、実リクエストまで検証します。データベースの[ロールバック](/docs/ja/guides/release-safety/rollback/)はデータを復元しません。
