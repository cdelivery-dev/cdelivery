## 作成と関連付け

シークレット画面で作成してから、アプリの設定で選択します。テキストは環境変数、ファイルは XConfig マウントに使用します。

## 権限

Reader はメタデータを一覧できます。Operator と Admin は作成、削除、関連付けができます。内容の読み戻し、ダウンロード、編集はできません。

## 制限

内容は空にできず、上限は 511,999 バイト、説明は 64 文字です。テキストは空白と末尾の改行を保持し、NUL を拒否します。ファイルはバイナリに対応します。OS の環境変数制限は保存上限より小さい場合があるため、大きな内容にはファイルを使用してください。

## 置換と削除

置き換える場合は別名で作成し、各アプリの参照を更新して動作を確認します。実行タスクとロールバック設定が不要になるまで古いリソースは削除できません。参照には名前と ID が含まれ、同名で再作成しても古い参照は置き換わりません。

## 実行時の動作

ファイルはモード 0444 で読み取り専用マウントされます。ローカルボリュームを持つアプリでもファイルシークレットを利用できますが、通常の XConfig アップロードは利用できません。XJob、XHealth、Hurl、Guardian は関連付けを継承し、候補の検証は候補の参照を使用します。通常の exec は起動時に注入した変数を自動継承しません。

## 可視性

名前と説明は公開されるメタデータです。アプリやタスクは内容をログに出力でき、自動的には秘匿されません。保護された原本を別途保存してください。既存の通常の環境変数やアップロードは自動変換されません。
