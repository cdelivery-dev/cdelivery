引数の解析とシェル実行を区別して主プロセスを設定します。

## コマンド

必要がなければイメージ標準を使います。引用符による引数分割はできますが、変数展開、パイプ、リダイレクトには明示的なシェルが必要です。

Hello イメージ（`ghcr.io/cdelivery-dev/hello:1.0.0`）で次のコマンドを使うと、環境変数 `GREETING` の値を起動ログに出力してから HTTP サーバーを起動します。

```sh
sh -c 'printf "%s\n" "$GREETING"; exec httpd -f -v -p 80 -h /www'
```

`GREETING=Hello` を設定して試せます。この変数はログ出力に使われます。

イメージにシェルと実行ファイルが必要です。主プロセスはフォアグラウンドで動かし、終了するとコンテナも終了します。

## 環境

環境変数には通常の値かテキストシークレットを指定できます。[シークレット](/docs/ja/guides/apps/secrets/) を使う場合は、変数名を入力し、ソースを**シークレット**に切り替えて作成済みのものを選びます。確定後、アプリ設定を保存してください。

名前は 1–128 文字で `=` を含めず、通常の値は 4096 文字までです。プログラムが実際に読む変数を指定します。`PORT=8080` だけではポート公開や待受は設定されません。

直接入力した通常の値は共有設定で、自動マスキング対象とは限りません。ファイルには対応する場合 [XConfig](/docs/ja/guides/apps/xconfig/) を使います。

## 検証

保存後、新しいタスクとログを確認します。変更なしでは再起動しません。パス、ツール、引用符を確認し、展開が文字列のままならシェルを確認します。

内部ループバックだけに待受すると他コンテナから到達できません。[ネットワーク](/docs/ja/guides/networking/connectivity/)は別途設定します。
