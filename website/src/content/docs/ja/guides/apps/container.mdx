引数の解析とシェル実行を区別して主プロセスを設定します。

## コマンド

必要がなければイメージ標準を使います。引用符による引数分割はできますが、変数展開、パイプ、リダイレクトには明示的なシェルが必要です。

```sh
sh -c 'exec ./server --port "$PORT"'
```

イメージにシェルと実行ファイルが必要です。主プロセスはフォアグラウンドで動かし、終了するとコンテナーも終了します。

## 環境

名前は 1–128 文字で `=` を含めず、値は 4096 文字までです。プログラムが実際に読む変数を指定します。`PORT=8080` だけではポート公開や待受は設定されません。

任意の値は共有設定で、自動マスキング対象とは限りません。ファイルには対応する場合 [XConfig](/docs/ja/guides/apps/xconfig/) を使います。

## 検証

保存後、新しいタスクとログを確認します。変更なしでは再起動しません。パス、ツール、引用符を確認し、展開が文字列のままならシェルを確認します。

内部ループバックだけに待受すると他コンテナーから到達できません。[ネットワーク](/docs/ja/guides/networking/connectivity/)は別途設定します。
