Operator または Admin がアプリと関連チェック、ジョブ、リリース検証を削除します。

## 手順

復旧が必要ならイメージ、設定、保存先を記録します。依存クライアントを切り替え、XHealth/XJob/Guardian を確認して削除し、一覧とタスク終了を確認します。

コンテナー終了は非同期なので、ネットワーク参照が一時的に残る場合があります。

## 残るもの

業務ボリューム、グループ、外部 DNS は残ります。データ削除は参照とバックアップを確認して[ボリューム管理](/docs/ja/administration/nodes/volumes/)で別途判断します。

アプリがないことはボリュームが空であることを意味しません。

## 復旧

同名で作り直すと別の識別情報になり、元の定義は戻りません。設定を再構成し、状態を持つアプリでは元ボリュームを確認してください。

グループが使用中なら終了と参照を確認します。失敗したリリースでは削除前に[ロールバック](/docs/ja/guides/release-safety/rollback/)を検討します。
