## データベースを登録

Admin が**依存関係 → 依存先を追加 → PostgreSQL** を開き、名前、元のアプリ、その PostgreSQL DSN を指定します。元のアプリはボリューム管理が有効なサーバーに固定し、すべてのマウントで ZFS ボリュームを使ってください。登録後は同じグループのアプリが参照できます。

## 検証用のクローン

新しいスナップショットのクローンを使い、書き込みは破棄し、本番は元のボリュームを使い続けます。クローンはクォータなしでプールを共有し、準備時に 10% 以上の空き容量が必要です。バックアップと復元の範囲は[データ永続化](/docs/ja/guides/apps/persistence/)を参照してください。

データベースの元アプリを更新した場合も、登録された PostgreSQL 依存先を直接参照しリリース検証に参加しているアプリが検証対象になります。

続いて、[アプリに接続を設定し SQL の変更を検証](/docs/ja/guides/apps/dependencies/postgresql/)します。
