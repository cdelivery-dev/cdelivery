## データベースを登録

Admin が**依存関係 → 依存先を追加 → PlanetScale** を開き、名前、プロバイダー発行の PostgreSQL DSN、サービストークンを入力します。DSN のユーザー名に含まれるブランチ識別用の接尾辞は残してください。保存すると全グループで参照できます。

## 検証用ブランチ

一時ブランチは準備開始のおよそ 5 分前の状態に復元されます。その時点で存在したデータを検証に使ってください。ブランチはネットワークストレージを持つ単一ノードです。既定では元のサイズを使い、Metal の場合は PS-5 を使います。

続いて、[アプリに接続を設定し SQL の変更を検証](/docs/ja/guides/apps/dependencies/postgresql/)します。
