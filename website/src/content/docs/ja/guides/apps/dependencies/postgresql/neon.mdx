## データベースを登録

Admin が**依存関係 → 依存先を追加 → Neon** を開き、名前、Neon 発行の PostgreSQL DSN、API キー、プロジェクト ID を入力します。DSN のコンピュートエンドポイントは指定したプロジェクトに属している必要があります。保存すると全グループで参照できます。

## 検証用ブランチ

SQL の検証時には、DSN が指す元のブランチから一時ブランチを作り、読み書き可能なエンドポイントを用意します。変更の送信時に CU を指定できます。空欄なら元のエンドポイントの最小 CU を使います。

続いて、[アプリに接続を設定し SQL の変更を検証](/docs/ja/guides/apps/dependencies/postgresql/)します。
