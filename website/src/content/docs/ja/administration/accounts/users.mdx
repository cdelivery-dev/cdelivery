初期設定で最初の Admin を作り、以降は管理画面で個別アカウントを追加します。

## 作成と編集

氏名、一意のメール、初期パスワード、[役割](/docs/ja/administration/accounts/roles/)を入力します。適切にパスワードを伝え、変更と二要素認証を依頼します。

Admin は氏名、メール、役割を変更できます。メールはログイン、通知、受信者識別にも使うため本人のアドレスを確認します。

メッセージ紐付けと購読はユーザー自身が行います。

## 復旧

パスワードリセットは全セッションを無効化しますが、API キーは残ります。漏洩したキーは別途失効します。

二要素認証リセットは独立操作です。本人確認後に実行し、再登録してもらいます。

## 削除

セッションとキーは認証できなくなりますが、共有アプリや外部認証は残ります。引き継ぎを先に行います。

Admin は自分を削除・降格できず、別 Admin が担当します。管理できない場合は[アクセス復旧](/docs/ja/administration/platform/recovery/)を使います。権限エラーは現在役割とキー上限を確認します。
