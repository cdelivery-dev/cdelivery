ホスト名は重複する場合があるため、ID とアドレスで対象を確認します。

## 参加

Admin が Worker または Manager の参加コマンドを取得し、[要件](/docs/ja/getting-started/requirements/)を確認して対象マシンで実行します。Ready、役割、アドレス、資源を確認し、ラベルを追加します。

Worker はタスクを実行し、Manager は管理にも参加します。参加情報は 30 分有効で再利用できます。再起動や期限切れ後は新しく取得し、発行元の権限変更でも無効になる場合があります。公開しないでください。

## 状態

Ready/Down/Disconnected は接続状態。Active は配置可、Pause は新規配置なし、Drain は排出状態。Reachable は Manager 接続です。収集警告は報告の古さで、必ずしもサーバー停止ではありません。

状態表示が全変更操作を提供するとは限りません。[指標](/docs/ja/guides/observability/metrics/server/)も確認します。

## 削除

自動移行、バックアップ、排出は行いません。固定アプリ、データ、コンポーネント、管理可用性を先に確認します。

ボリュームは残り、オフラインの終了は確認できません。再参加で ID が変わる場合は固定指定とラベルを見直します。参加失敗は IP、期限、Docker、内部ポートを確認します。
