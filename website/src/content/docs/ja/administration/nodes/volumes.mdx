ボリュームはサーバー固有で、別マシンの同名ボリュームは別データです。

## 作成

Admin が cdelivery-agent を有効化します。対象サーバーの一覧で有効な名前と任意の最大 256 文字の説明を設定し、同じサーバーの[状態を持つアプリ](/docs/ja/guides/apps/persistence/stateful/)へマウントして保持を検証します。

## 容量

サイズ計算はデータを走査するため時間がかかります。未表示は空を意味しません。総量と空きはホストの情報です。予約済みの内部ボリュームは通常業務用として管理しません。

## 削除と調査

<Aside type="caution">
ボリュームを削除すると、そのローカルデータが失われます。アプリを削除してもボリュームは残ります。
</Aside>

説明の保存に失敗した場合は、一覧を更新して作成済みボリュームの説明を編集します。

参照と復元可能なバックアップを確認します。使用中なら終了待ちや参照解除を行います。コンポーネント無効化はデータを消しません。

一覧失敗はサーバーと agent、不在は ID と名前を確認します。他マシンで同名作成しても復旧できません。[永続化](/docs/ja/guides/apps/persistence/)を参照します。
