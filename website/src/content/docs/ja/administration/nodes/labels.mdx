ラベルでアプリやコンポーネントの配置候補をまとめます。

## 設定

Admin が `web` や `storage` などを付け、アプリの[配置](/docs/ja/guides/apps/placement/)で選びます。

1 台最大 32 個、名前は 1–16 文字の小文字・数字・ハイフンで、先頭末尾ハイフンと予約名は禁止です。任意のキー値検索ではありません。

## 影響

削除すると候補がなくなり得ます。追加前にはアーキテクチャ、資源、通信、データを確認します。

ID 固定アプリは同じラベルだけで移動しません。ボリュームも複製しません。

## 確認

保存後に再表示し、実配置を確認します。待機時は可用性、予約、上限を調べます。

API の `labels` はプラットフォームの配置ラベル全体を置換し、空配列は削除します。必要なラベルを落とさないよう現在値を読んでから変更します。[サーバー管理](/docs/ja/administration/nodes/)も参照してください。
