管理資源、アプリ定義、アカウント、認証情報を削除し、ボリュームと説明は保持します。
</Aside>

## アンインストール

管理サーバーの対話型端末で Docker CLI、jq、ローカル Unix socket を使います。設定、イメージ、サーバーとボリュームを記録し、バックアップして資源作成を停止します。

```sh
curl -fsSL https://cdelivery.dev/uninstall.sh | sh
```

表示された Docker の接続先と削除対象を確認し、`y` または `Y` を入力して Enter で実行します。何も入力せずに Enter を押す、別の文字列を入力する、または Ctrl+C で中止できます。削除対象が残っていない場合は、確認せずに終了します。

最初に主プログラムを止め、管理対象の資源を削除します。完了を表示する前に、管理対象のネットワークがローカル Docker のネットワーク一覧から消えるまで最大 120 秒待ちます。タイムアウト時は残っているネットワークを表示し、エラーで終了します。Docker、ボリューム、外部 DNS、オブジェクト保存先、外部アカウントは削除しません。

## 検証

管理資源の除去とボリューム保持を確認します。終了は非同期で、オフライン機器は再接続後に調べます。

失敗時は通信、参照、権限を修正して同じコマンドを再実行し、再度プレビューして確認します。途中で再インストールや同名再作成をしません。

保持データの削除は別判断です。新しいインストールは新しい管理情報を作るため、業務復旧には記録とストレージ復元が必要です。
