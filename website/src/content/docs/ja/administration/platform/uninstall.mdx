管理資源、アプリ定義、アカウント、認証情報を削除し、ボリュームと説明は保持します。

## プレビュー

管理サーバーで Docker CLI、jq、ローカル Unix socket を使います。設定、イメージ、サーバーとボリュームを記録し、バックアップして資源作成を停止します。

```sh
curl -fsSLo /tmp/cdelivery-uninstall.sh https://cdelivery.dev/uninstall.sh
sh /tmp/cdelivery-uninstall.sh
```

引数なしは対象一覧だけです。接続先と資源を確認します。

## 実行

```sh
sh /tmp/cdelivery-uninstall.sh --yes
```

最初に主プログラムを止めます。Docker、ボリューム、外部 DNS、オブジェクト保存先、外部アカウントは削除しません。

## 検証

管理資源の除去とボリューム保持を確認します。終了は非同期で、オフライン機器は再接続後に調べます。

失敗時は通信、参照、権限を修正して `--yes` を再実行します。途中で再インストールや同名再作成をしません。

保持データの削除は別判断です。新しいインストールは新しい管理情報を作るため、業務復旧には記録とストレージ復元が必要です。
