アプリと共通ネットワークを整理しますが、アカウントの閲覧範囲は分離しません。

## 作成

Admin が一意な 1–16 文字の小文字・数字・ハイフン名を指定します。先頭末尾ハイフンと予約名は使えず、説明は最大 256 文字です。

アプリ作成時に選びます。アプリ名は全体で一意で、コンソールでグループ名変更や既存アプリ移動はできません。[内部通信](/docs/ja/guides/networking/connectivity/)を確認します。

## 説明

用途や担当を記録するもので、権限や配置を変えません。ネットワーク作成後に説明保存だけ失敗する場合は、一覧を更新して補います。

patch で省略すると保持し、明示的に空にすると削除します。

## 削除

アプリとネットワーク参照を先に解消します。非同期終了により一時的に使用中になる場合があります。

業務ボリュームは残ります。[ボリューム](/docs/ja/administration/nodes/volumes/)でサーバーと名前を記録し、接続問題はグループ、ポート、待受、サーバー間通信を確認してください。
