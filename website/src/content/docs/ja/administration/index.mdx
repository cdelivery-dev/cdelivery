資源、アカウント、保守を管理します。プラットフォームの変更は通常 Admin が行います。

## 初期順序

サーバーとアドレス、グループ、アプリを確認し、個別アカウントと役割を作ります。その後、収集、チャネル、ドメインを追加します。

グループは権限を隔離せず、ラベルはデータを複製しません。削除前に依存関係を確認します。

## 検証

保存後の一覧、実行、イベント、アクセスを確認します。置換や収集は継続する場合があります。復旧はコンテナー起動だけでなく業務データも検証します。
