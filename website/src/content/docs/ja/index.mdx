インストールからアプリの運用、ネットワーク、監視、自動化、プラットフォーム管理までを説明します。

## はじめに

1. [概要](/docs/ja/getting-started/introduction/)で構成と用語を確認します。
2. [事前準備](/docs/ja/getting-started/requirements/)でサーバーとネットワークを整えます。
3. [インストール](/docs/ja/getting-started/installation/)で管理者を作成します。
4. [最初のアプリ](/docs/ja/getting-started/first-app/)を公開し、実際の応答を確認します。
5. [コンソール](/docs/ja/getting-started/console/)で各機能の場所を確認します。

## 管理

[プラットフォーム管理](/docs/ja/administration/)ではサーバー、アカウント、保守を扱います。外部ツールは [API/MCP](/docs/ja/guides/automation/api-mcp/) を参照してください。

例のアドレスや認証情報を自分の値に置き換え、保存後は実際の動作を確認します。データを変更する操作では、バックアップと復元も確認してください。
