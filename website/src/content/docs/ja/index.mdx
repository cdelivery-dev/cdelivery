CDelivery はコンテナーイメージのデプロイと、1 台以上のサーバーでのアプリ運用を支援します。

## 利用を始める

1. [インストール前の準備](/docs/ja/getting-started/requirements/)：サーバーのアドレス、ネットワーク、アクセス方法を準備します。
2. [CDelivery のインストール](/docs/ja/getting-started/installation/)：プラットフォームを起動し、管理者を作成します。
3. [最初のアプリをデプロイ](/docs/ja/getting-started/first-app/)：Nginx をデプロイしてアクセスを確認します。

## 基本概念

| 対象 | 役割 |
| --- | --- |
| サーバー | 計算リソースとローカルストレージを提供します。 |
| グループ | アプリを整理し、グループ内の通信ネットワークを提供します。 |
| アプリ | コンテナーイメージ、設定、望ましい実行状態をまとめたものです。 |
| レプリカ | アプリの実行中のインスタンスです。 |

グループはアカウントの権限を分離しません。[ロールと権限](/docs/ja/administration/accounts/roles/)を参照してください。データを保持する場合は[データの永続化](/docs/ja/guides/apps/persistence/)を確認します。レプリカやアプリのロールバックはバックアップの代わりにはなりません。
