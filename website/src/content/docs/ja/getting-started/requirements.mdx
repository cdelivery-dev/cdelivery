サーバー 1 台で始められます。複数のサーバーを使う場合は、互いに到達できる安定したアドレスが必要です。

## サーバー間通信のアドレス

他サーバーが到達できるアドレスを選びます。ブラウザー用アドレスとは異なって構いません。ループバックは他サーバー向けに使えません。

## ネットワークとアクセス

| ポート | 用途 | 許可範囲 |
| --- | --- | --- |
| TCP 9000 | コンソール/API | 管理ネットワーク |
| TCP 80/443 | Pingress | 利用クライアント |
| 公開ポート | アプリ | 必要なクライアント |
| TCP 2377 | 管理通信 | 参加サーバー間 |
| TCP/UDP 7946 | 検出・通信 | 参加サーバー間 |
| UDP 4789 | アプリ通信 | 参加サーバー間 |

ホストとクラウド双方のファイアウォールを確認します。内部ポートは参加サーバーに限定します。[Docker の要件](https://docs.docker.com/engine/network/drivers/overlay/#requirements)も参照してください。

リモートサーバーの管理には SSH トンネルを利用できます。

```sh
ssh -L 9000:127.0.0.1:9000 your-user@server.example.com
```

トンネルを維持して localhost:9000 を開きます。例の 8080 は別途転送します。

## データの計画

状態を持つアプリを作る前に保存先とバックアップを決めます。ドメインは必須ではありません。[IPv6](/docs/ja/guides/networking/faq/)を確認し、[インストール](/docs/ja/getting-started/installation/)へ進みます。
