Nginx をポート公開し、実際の HTTP 応答まで確認します。

## 準備

Admin がグループを作成し、Operator または Admin がアプリを作成します。TCP 8080 を許可するか転送します。

```sh
ssh -L 9000:127.0.0.1:9000 -L 8080:127.0.0.1:8080 your-user@server.example.com
```

## 作成

グループ `demo`、アプリ `hello-web`、イメージ `nginx:stable-alpine` を指定します。標準コマンドと固定 1 レプリカを維持し、内部 **80** を **8080/TCP** で公開します。保存後、実行を待ちます。

ドメイン、ボリューム、独自コマンドは不要です。[公式イメージ](https://hub.docker.com/_/nginx)は Nginx をフォアグラウンド起動します。

## 検証

`http://SERVER_IP:8080`、またはトンネルの localhost を開きます。

```sh
curl -i http://localhost:8080
```

HTTP 200 と Nginx ページを確認し、レプリカとログも見ます。取得失敗はレジストリー・アーキテクチャ、終了はコマンド・ログ、接続失敗は割り当て・IP・ファイアウォールを調べます。ドメインルートなら内部 80 を指定します。

片付ける場合はアプリを削除し、コンテナー終了後に空のグループを削除します。[コンソール](/docs/ja/getting-started/console/)へ進んでください。
