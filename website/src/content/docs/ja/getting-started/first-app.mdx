Hello をポート公開し、実際の HTTP 応答まで確認します。

## 準備

動作する CDelivery 環境を用意します。グループ作成には Admin、アプリのデプロイには Operator または Admin が必要です。サーバーが GHCR から公開 Hello イメージを取得でき、TCP 8080 が空いていて手元のコンピューターから到達できることを確認します。

SSH を使う場合は手元のコンピューターで次を実行し、セッションを開いたままにします。

```sh
ssh -L 9000:127.0.0.1:9000 -L 8080:127.0.0.1:8080 your-user@server.example.com
```

## 手順

<Steps>

<Step title="グループを作成">

`demo` という名前のグループを作成します。

</Step>

<Step title="アプリを設定">

そのグループに `hello-web` アプリを作成し、イメージに `ghcr.io/cdelivery-dev/hello:1.0.0` を指定します。標準コマンドと固定 1 レプリカを維持します。

</Step>

<Step title="ポートを公開">

コンテナポート **80** をサーバーポート **8080** に TCP で公開します。

</Step>

<Step title="アプリをデプロイ">

保存して、レプリカが実行状態になるまで待ちます。

</Step>

</Steps>

ドメイン、ボリューム、独自コマンドは不要です。Hello は BusyBox httpd を使い、標準でフォアグラウンド起動します。

## 検証

手元のコンピューターで `http://SERVER_IP:8080` を開くか、次のコマンドを実行します。`SERVER_IP` は到達可能なサーバーのアドレスに置き換えてください。

```sh
curl -i http://SERVER_IP:8080
```

SSH トンネルを使う場合はセッションを開いたままにし、手元のコンピューターで代わりに次を実行します。

```sh
curl -i http://localhost:8080
```

HTTP 200 と、`Hostname`、`IP`、`Method`、`URI`、リクエストヘッダーを含むプレーンテキスト応答を確認します。レプリカとログも見ます。取得失敗はレジストリ・アーキテクチャ、終了はコマンド・ログ、接続失敗は割り当て・IP・ファイアウォールを調べます。ドメインルートなら内部 80 を指定します。

片付ける場合はアプリを削除し、コンテナ終了後に空のグループを削除します。[アプリ管理](/docs/ja/guides/apps/)へ進んでください。
