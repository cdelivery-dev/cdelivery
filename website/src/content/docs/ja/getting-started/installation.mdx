## 事前準備

管理権限でインストーラーを実行し、コンソールへのアクセスを確認します。

先に[インストール前の準備](/docs/ja/getting-started/requirements/)を済ませます。

macOS は Docker を先に起動します。IPv6 の問題は表示された診断に従い、非対話実行では手動選択を前提にしません。

## 手順

<Steps>

<Step title="インストーラーを実行">

```sh
curl -fsSL https://cdelivery.dev/install.sh | sh
```

サーバー間通信のアドレスを指定する場合：

```sh
curl -fsSL https://cdelivery.dev/install.sh | sh -s -- --advertise-addr 10.0.0.10
```

このマシンに割り当てられ、他サーバーから到達できる IP に置き換えます。ドメインではなく、公開 IP とも限りません。

</Step>

<Step title="ダッシュボードを開く">

`http://SERVER_IP:9000`、macOS やトンネルでは `http://localhost:9000` を開きます。

</Step>

<Step title="最初の管理者を作成">

氏名、メールアドレス、パスワードを入力して最初の Admin を作成すると、自動的にログインしてプラットフォーム設定に進みます。

プラットフォーム設定では、ドメインの設定と Insight の有効化ができます。そのままダッシュボードに進むこともできます。Insight の初期値はローカル保存・90 日です。以後はプラットフォーム設定と Insight の各画面で管理します。

既存環境の再開では元のアカウントを使います。再実行はパスワードや既存通信アドレスをリセットしません。

</Step>

</Steps>

## 結果の確認

- 管理者アカウントでログインできること。
- サーバー一覧のアドレスとリソースが想定どおりであること。
- グループとプラットフォーム設定を開けること。

## トラブルシューティング

ダウンロード失敗は DNS/HTTPS、Docker はサービス・バージョン・権限、ブラウザーのタイムアウトは IP・9000・ファイアウォール・トンネルを確認します。アカウントは[復旧手順](/docs/ja/administration/platform/recovery/)を参照し、診断を共有する前に機密情報を除いてください。

初期設定後にログイン画面が表示された場合は、作成したアカウントでログインします。
