CDelivery はコンテナーイメージのデプロイと、1 台以上のサーバーでのアプリ運用を支援します。

## 主な対象

| 対象 | 役割 |
| --- | --- |
| アプリ | イメージ、コマンド、ネットワーク、リソース、ストレージ |
| グループ | アプリの整理と共通ネットワーク |
| サーバー | 計算資源とローカルストレージ |
| アカウント | Reader、Operator、Admin の権限 |

グループはアカウント権限の境界ではありません。アプリ名はプラットフォーム全体で一意です。ローカルボリュームは特定のサーバーに属し、レプリカやロールバックはバックアップを代替しません。

## 機能

Pingress はドメインと HTTPS、XHealth はチェック、Guardian は候補構成の検証、Insight はログ・指標・イベントの収集、XJob は独立コンテナーでの定期実行を担当します。

AI の会話は紐づくユーザーの権限、自動当番は専用の役割で動作します。各機能には設定が必要で、コンソールのインストールだけでは証明書や収集、モデル接続は完了しません。

## 開始

[事前準備](/docs/ja/getting-started/requirements/)、[インストール](/docs/ja/getting-started/installation/)、[最初のアプリ](/docs/ja/getting-started/first-app/)の順に進めます。Operator はアプリを操作し、Admin はグループやサーバーを管理します。
