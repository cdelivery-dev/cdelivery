アプリ操作、プラットフォーム管理、個人設定をそれぞれの画面で行います。

## 場所

| 領域 | 操作 |
| --- | --- |
| グループ/アプリ | 設定、レプリカ、デプロイ |
| ログ/指標 | 実行とリソースの調査 |
| XHealth/Guardian/XJob | チェック、検証、定期処理 |
| サーバー | 状態、ラベル、ボリューム、指標 |
| 設定 | コンポーネント、モデル、チャネル、ユーザー、バージョン |
| アカウント | パスワード、二要素認証、キー、通知 |

Reader は共有情報と自分のアカウント、Operator はアプリ操作、Admin は全体管理を行います。[権限](/docs/ja/administration/accounts/roles/)を確認してください。

## 実行状態

保存成功後も取得、配置、起動は続くことがあります。希望レプリカと実数、ログ、実際のリクエストを比較します。

空のグラフは未収集や遅延の場合もあります。クエリー失敗とは区別し、欠測を使用量ゼロと扱いません。

## 日常の流れ

状態確認、変更、タスク・イベント・アクセス検証の順に進めます。削除では残るデータも確認します。

Admin がチャネルを設定し、各ユーザーが本人 ID と購読を設定します。[監視](/docs/ja/guides/observability/)と[管理](/docs/ja/administration/)を参照してください。
