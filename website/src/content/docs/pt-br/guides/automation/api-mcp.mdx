REST e MCP compartilham operações e autorização; os caminhos pertencem à sua instância.

## Criar chave

Em Conta → MCP/API keys, informe nome de 1–64 bytes UTF-8, teto de perfil e expiração futura opcional. Copie imediatamente: exibição única.

Separe por ferramenta. Perfil não supera o efetivo na criação e continua limitado pelo usuário atual. Troca de senha não revoga; exclusão de usuário invalida.

## REST

Defina URL e chave no ambiente local:

```sh
curl --fail-with-body "$CDELIVERY_URL/api/me" \
  -H "Authorization: Bearer $CDELIVERY_API_KEY"
```

Espere informações da conta. `/scalar` documenta o schema instalado.

Atualizações usam patch: omitir preserva; `null` limpa apenas campos compatíveis; patch vazio é válido. Enums distinguem maiúsculas, como Reader/Operator/Admin.

## MCP

Configure o cliente HTTP remoto com `/mcp` e `Authorization: Bearer YOUR_API_KEY`. Liste as ferramentas e teste uma leitura para verificar a conta e as permissões antes de escrever.

## Diagnóstico

401: credencial inválida/expirada/revogada ou usuário indisponível. 403: permissão. 422: campos/requisitos. Conexão: URL, TLS e proxy.

Após revogar, confirme recusa da chave. Veja [perfis](/docs/pt-br/administration/accounts/roles/).

[Segredos](/docs/pt-br/guides/apps/secrets/): Reader pode listar metadados. Operator e Admin podem criar, excluir e vincular segredos. O conteúdo não pode ser consultado novamente, baixado ou editado.


| REST | MCP / Agent |
| --- | --- |
| `POST /api/secrets` | `secret_create` |
| `GET /api/secrets?kind=Text` | `secret_list` |
| `DELETE /api/secrets/{name}` | `secret_delete` |

`POST /api/secrets`:

```json
{"name":"api-token","content":{"Text":"REPLACE_LOCALLY"}}
```

- `content.File`: Base64.
- `container_options.env`: `[{"name":"TOKEN","value":{"name":"api-token","id":"SECRET_ID"}}]`.
- `POST /api/apps` → `xconfigs`: `[{"target":"/app/credentials","secret":{"name":"api-file","id":"SECRET_ID"}}]`.
- `PATCH /api/apps/{name}` → `xconfigs`: `[{"Secret":{"target":"/app/credentials","secret":{"name":"api-file","id":"SECRET_ID"}}}]`.
