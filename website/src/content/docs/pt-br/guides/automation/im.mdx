Admin conecta canais; cada usuário vincula sua identidade e escolhe assinaturas.

## Canais

<CardGrid>

<Card title="E-mail" href="/docs/pt-br/guides/automation/im/email/" icon="ph:envelope-simple">
  Credenciais: SMTP; IMAP opcional. Identidade: E-mail da conta.
</Card>

<Card title="Slack" href="/docs/pt-br/guides/automation/im/slack/" icon="ph:slack-logo">
  Credenciais: Tokens bot/app. Identidade: Member ID.
</Card>

<Card title="Telegram" href="/docs/pt-br/guides/automation/im/telegram/" icon="ph:telegram-logo">
  Credenciais: Token bot. Identidade: ID numérico.
</Card>

<Card title="Discord" href="/docs/pt-br/guides/automation/im/discord/" icon="ph:discord-logo">
  Credenciais: Token bot. Identidade: User ID.
</Card>

<Card title="Lark" href="/docs/pt-br/guides/automation/im/lark/" icon="ph:chat-circle-dots">
  Credenciais: App ID/Secret. Identidade: open_id.
</Card>

<Card title="Feishu" href="/docs/pt-br/guides/automation/im/feishu/" icon="ph:chat-circle-dots">
  Credenciais: App ID/Secret. Identidade: open_id.
</Card>

</CardGrid>

Nome visível, grupo ou bot não substituem ID pessoal.

## Configurar

Siga criação, permissões, instalação e recebimento do canal. Salve credenciais, vincule seu próprio ID. Novas vinculações recebem notificações por padrão; você pode desativá-las. Conversas precisam de [modelo](/docs/pt-br/guides/automation/models/); teste pergunta de leitura.

ID de outra pessoa pode expor suas notificações e permissões a ela.

## Diagnóstico

Separe credenciais, rede, eventos, vínculo, assinatura e modelo. Avatar não prova entrega nem vínculo correto. Consulte [notificações](/docs/pt-br/guides/automation/im/notifications/) para perfis e idioma.
