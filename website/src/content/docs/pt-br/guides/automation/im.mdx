Admin conecta canais; cada usuário vincula sua identidade e escolhe assinaturas.

## Canais

| Canal | Credenciais | Identidade |
| --- | --- | --- |
| [E-mail](/docs/pt-br/guides/automation/im/email/) | SMTP; IMAP opcional | E-mail da conta |
| [Slack](/docs/pt-br/guides/automation/im/slack/) | Tokens bot/app | Member ID |
| [Telegram](/docs/pt-br/guides/automation/im/telegram/) | Token bot | ID numérico |
| [Discord](/docs/pt-br/guides/automation/im/discord/) | Token bot | User ID |
| [Lark](/docs/pt-br/guides/automation/im/lark/) | App ID/Secret | open_id |
| [Feishu](/docs/pt-br/guides/automation/im/feishu/) | App ID/Secret | open_id |

Nome visível, grupo ou bot não substituem ID pessoal.

## Configurar

Siga criação, permissões, instalação e recebimento do canal. Salve credenciais, vincule seu próprio ID e ative notificações. Conversas precisam de [modelo](/docs/pt-br/guides/automation/models/); teste pergunta de leitura.

ID de outra pessoa pode expor suas notificações e permissões a ela.

## Diagnóstico

Separe credenciais, rede, eventos, vínculo, assinatura e modelo. Avatar não prova entrega nem vínculo correto. Consulte [notificações](/docs/pt-br/guides/automation/im/notifications/) para papéis e idioma.
