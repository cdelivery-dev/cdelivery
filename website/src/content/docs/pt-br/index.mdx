CDelivery permite implantar imagens de contêiner e manter aplicações em um ou vários servidores.

## Primeiros passos

1. [Antes de instalar](/docs/pt-br/getting-started/requirements/): Prepare os endereços, a rede e o acesso ao console.
2. [Instalar o CDelivery](/docs/pt-br/getting-started/installation/): Inicie a plataforma e crie uma conta de administrador.
3. [Publicar a primeira aplicação](/docs/pt-br/getting-started/first-app/): Implante o Nginx e verifique o acesso.

## Conceitos principais

| Objeto | Função |
| --- | --- |
| Servidor | Fornece recursos de computação e armazenamento local. |
| Grupo | Organiza aplicações e fornece uma rede compartilhada. |
| Aplicação | Combina uma imagem de contêiner, configuração e os parâmetros de execução desejados. |
| Réplica | Uma instância em execução de uma aplicação. |

Os grupos não isolam permissões de contas; veja [funções e permissões](/docs/pt-br/administration/accounts/roles/). Para preservar dados, leia [persistência de dados](/docs/pt-br/guides/apps/persistence/). Réplicas e reversões de aplicações não substituem backups.
