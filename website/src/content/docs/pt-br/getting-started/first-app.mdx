Publique Hello por uma porta e confirme uma resposta HTTP real.

## Preparar

Use uma instalação funcionando. Admin cria o grupo; Operator ou Admin publica a aplicação. O servidor deve conseguir baixar a imagem pública do Hello do GHCR. A porta TCP 8080 deve estar livre e acessível pelo seu computador.

Para acessar por SSH, execute este comando no seu computador e mantenha a sessão aberta:

```sh
ssh -L 9000:127.0.0.1:9000 -L 8080:127.0.0.1:8080 your-user@server.example.com
```

## Passos

<Steps>

<Step title="Criar um grupo">

Crie um grupo chamado `demo`.

</Step>

<Step title="Configurar a aplicação">

Crie a aplicação `hello-web` nesse grupo com a imagem `ghcr.io/cdelivery-dev/hello:1.0.0`. Mantenha o comando padrão da imagem e uma réplica fixa.

</Step>

<Step title="Publicar uma porta">

Publique a porta do contêiner **80** como porta do servidor **8080**, usando TCP.

</Step>

<Step title="Publicar a aplicação">

Salve a aplicação e aguarde a réplica entrar em execução.

</Step>

</Steps>

Não é preciso domínio, volume ou comando personalizado. Hello usa BusyBox httpd e inicia em primeiro plano por padrão.

## Conferir

No seu computador, abra `http://SERVER_IP:8080` ou execute o comando abaixo. Substitua `SERVER_IP` pelo endereço acessível do servidor.

```sh
curl -i http://SERVER_IP:8080
```

Se usar o túnel SSH, mantenha a sessão aberta e execute este comando no seu computador:

```sh
curl -i http://localhost:8080
```

Espere HTTP 200 e uma resposta em texto simples com `Hostname`, `IP`, `Method`, `URI` e cabeçalhos da requisição. Confira também tarefas e logs.

Se não baixa, verifique registro e arquitetura. Se encerra, restaure comando padrão e leia logs. Se não conecta, confira mapeamento, IP, firewall e túnel. Uma rota de domínio usaria a porta interna 80.

Para limpar, remova aplicação, aguarde contêineres e exclua o grupo vazio. Continue pelo [gerenciamento de aplicações](/docs/pt-br/guides/apps/).
