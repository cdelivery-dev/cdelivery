分组用于组织应用，并为组内应用提供共同的通信网络。可以按项目或环境命名，例如 `demo`、`production`。分组不是账户权限边界，各角色可读取其允许的全部分组共享信息。

## 创建和使用

1. Admin 打开分组列表并创建分组。
2. 填写 1–16 位名称，使用小写字母、数字或连字符，不以连字符开头或结尾，不使用保留名称。
3. 按需填写说明，最多 256 个字符。
4. 创建应用时选择该分组。
5. 检查应用列表和[组内通信](/docs/zh-cn/guides/networking/connectivity/)。

应用名称在平台内唯一，不能通过换一个分组复用已存在的应用名称。控制台创建后不提供重命名分组或移动应用的操作，因此创建前确定用途和名称。

## 维护说明

说明用于记录用途、环境或负责人，不影响调度与权限。创建分组时若网络已建立但说明保存失败，分组可能已经存在；刷新列表后补充说明，无需重复创建。

更改说明不会重建应用。通过 API 更新时，省略说明表示保持原值，显式清空才会移除说明。

## 删除与排障

先删除或处理组内应用和网络引用，再删除分组。应用删除后容器退出是异步的，立即删除分组可能提示仍被占用；确认任务退出后重试。

删除分组不会自动清理业务数据卷。需要保留数据时，在[数据卷管理](/docs/zh-cn/administration/nodes/volumes/)中记录所在服务器和卷名。

若出现名称冲突，检查现有分组；若组内应用无法互访，检查是否属于同一分组、目标容器端口、监听地址和服务器间网络。
