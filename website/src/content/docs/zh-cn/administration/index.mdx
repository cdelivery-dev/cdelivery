## 建议的初始化顺序

安装并创建首个 Admin 后，先核对服务器地址和状态，再创建分组与应用。需要多人协作时，为每个人创建独立账户并分配适当角色。随后根据需要配置域名、观测、消息渠道和 AI。

分组不隔离账户权限，服务器标签也不提供数据复制。更改调度或删除资源前，应核对依赖这些资源的应用和平台组件。

## 管理操作如何验收

保存成功表示操作请求已完成或已提交，容器更新、加入服务器和后台采集仍可能需要时间。操作后分别检查资源列表、实际运行状态、事件和访问结果。备份与恢复还需要验证业务数据，不能只看容器处于运行中。
