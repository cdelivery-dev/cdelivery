平台管理负责运行应用所需的资源、账户和 CDelivery 自身。Reader 可以查看共享运行信息，平台资源和设置的修改通常需要 Admin；应用日常操作由 Operator 或 Admin 完成。

## 按任务查找

| 任务 | 入口 |
| --- | --- |

| 创建、检查和删除本地存储 | [数据卷管理](/docs/zh-cn/administration/nodes/volumes/) |
