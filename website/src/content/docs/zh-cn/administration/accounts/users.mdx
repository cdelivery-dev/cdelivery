安装初始化创建首个 Admin。后续用户由 Admin 在设置的用户管理中创建，团队成员应使用独立账户。

## 创建与编辑

1. 打开用户管理，填写姓名、邮箱、初始密码和角色。
2. 确认邮箱唯一且属于使用者，角色按[权限表](/docs/zh-cn/administration/accounts/roles/)选择。
3. 保存后通过适当方式交付初始密码。
4. 让使用者登录、修改密码并配置两步验证。
5. 如需通知，由使用者完成个人消息绑定和订阅。

管理员可修改用户姓名、邮箱和角色。邮箱是登录标识，也影响邮件通知和邮件入站身份；变更前确认收件地址由正确人员控制。

## 重置登录

重置密码后，该用户全部浏览器会话立即失效，需要使用新密码重新登录。API 密钥与密码独立，仍保持有效；若怀疑密钥泄露，不能只改密码。

重置两步验证是独立操作，不因普通密码重置自动完成。丢失验证器时，先核对人员身份，再重置两步验证，由用户重新绑定。

## 删除与交接

删除用户会使其会话和 API 密钥无法继续认证。删除不会替你删除共享应用、撤销外部服务商凭证或回收已导出的数据。先完成业务交接，再删除账户。

Admin 不能删除自己或把自己降级。需要变更当前管理员时，先由另一位 Admin 接手；失去全部管理访问时参阅[恢复管理访问](/docs/zh-cn/administration/platform/recovery/)。

创建失败时检查邮箱重复与表单校验；用户反馈“权限不足”时核对实时角色以及所用 API 密钥的角色上限。
