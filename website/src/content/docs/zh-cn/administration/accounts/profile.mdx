个人账户集中管理姓名、界面语言、主题、密码、两步验证、消息绑定和 API 密钥。所有角色都可以管理自己的账户；邮箱和角色变更由管理员处理。

## 修改密码

打开账户的密码页面，输入当前密码和新密码并保存。密码修改后，所有浏览器会话都会失效，包括当前会话，需重新登录。API 密钥不受改密影响；需要停止外部工具时单独撤销密钥。

如果不记得当前密码，请联系 Admin 重置；管理员也无法登录时使用[恢复管理访问](/docs/zh-cn/administration/platform/recovery/)。

## 两步验证

1. 打开两步验证页面，用验证器扫描二维码或输入显示的密钥。
2. 输入当前密码和验证器的六位代码。
3. 提交后确认页面显示已启用。
4. 在新的登录会话中验证密码和动态代码均可正常使用。

仅扫描二维码不算启用，必须完成提交验证。二维码和密钥可用于生成登录代码，不要公开分享。代码持续失败时检查设备时间、账户条目和代码是否已经过期。

关闭两步验证需要当前密码和当前代码。丢失验证器时由管理员重置，或通过主机救援恢复；不要假定平台提供备用恢复码。

## 偏好与连接

界面支持八种语言，主题可选择明暗或跟随系统。消息平台绑定填写自己的不可变用户 ID，通知开关独立控制是否接收告警。具体 ID 获取方式见[消息渠道](/docs/zh-cn/guides/automation/im/)。

API 密钥只在创建时显示一次，适合外部工具，不要把浏览器 Cookie 当作长期集成凭证。参阅 [API 与 MCP](/docs/zh-cn/guides/automation/api-mcp/)。
