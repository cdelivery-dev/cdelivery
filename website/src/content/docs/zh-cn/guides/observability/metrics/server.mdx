从服务器列表打开目标服务器，进入指标页面。服务器指标用于判断整台机器的资源情况，与单个应用容器的指标范围不同。

## 主要指标

| 类别 | 用途 |
| --- | --- |
| CPU | 查看总利用率、用户态、内核态、I/O 等待和被占用时间 |
| 内存与交换 | 判断可用容量、压力及交换使用 |
| 网络 | 查看物理网卡的收发速率 |
| 文件系统 | 查看容量、使用比例和 inode 使用情况 |
| 压力指标 | 判断 CPU、内存或 I/O 等待对任务的影响 |
| 运行时间 | 辅助识别服务器重启或采样连续性变化 |

文件系统指标针对被采集的本地可写块设备文件系统。不要假设列表覆盖每个容器挂载、远程文件系统或所有临时目录。

## 时间与单位

普通服务器采样默认每 5 秒进行，文件系统采样每 5 分钟进行。文件系统图表不会因为你将普通采样间隔改为 1 秒就获得秒级磁盘容量数据。

CPU 核数、百分比、内存字节量、网络字节每秒和运行时间各有不同单位。扩大查询时间范围会改变聚合粒度；缺失时间桶不代表资源用量为零。

## 判断容量问题

1. 对照服务器上的应用副本和资源预留。
2. 检查问题时间段的 CPU、内存及文件系统变化。
3. 查看是否同时出现应用重启、调度等待或日志写入失败。
4. 检查 inode 和容量两个维度，避免磁盘有剩余空间却无法创建文件。
5. 在采取清理或迁移措施前确认数据所属资源。

容器资源预留影响调度，服务器实际用量反映运行情况，两者不能互相替代。调整应用设置前参见[资源限制](/docs/zh-cn/guides/apps/resources/)。

## 采集异常

页面没有指标时，先检查 Insight Agent、服务器状态及最近上报时间。服务器刚加入、刚重启、采集服务尚未运行或存储暂时不可用，都可能造成缺失。

采集静默是诊断线索，不是服务器已经宕机的充分证据。应结合服务器连接、任务状态及平台错误进一步确认。

## 与管理操作配合

需要修改标签时进入[服务器标签](/docs/zh-cn/administration/nodes/labels/)；需要查看或清理应用数据卷时进入[数据卷管理](/docs/zh-cn/administration/nodes/volumes/)。

不要仅根据一张容量图表删除未知数据目录。平台数据、应用卷、镜像和日志可能具有不同的保留与恢复要求。
