依赖让应用通过[环境变量](/docs/zh-cn/guides/apps/container/)引用其他应用的主机名或 PostgreSQL 连接，也让[发布检查](/docs/zh-cn/guides/release-safety/guardian/)识别直接消费者。把主机名或 DSN 填成普通值，不会建立这种关系。

- [APP 依赖](/docs/zh-cn/guides/apps/dependencies/app/) — 以订单服务调用用户服务为例，配置依赖并验证任一方更新后两者能否正常协作。
- [PostgreSQL 数据库依赖](/docs/zh-cn/guides/apps/dependencies/postgresql/) — 让 APP 连接数据库，并用 APP 的业务检查验证一条 SQL 能否在生产执行。

## 引用依赖

Operator 和 Admin 可以编辑应用配置：

1. 添加环境变量，将来源切换为**依赖**。
2. 选择依赖和输出字段。
3. 确认选择，再保存整个应用配置。
