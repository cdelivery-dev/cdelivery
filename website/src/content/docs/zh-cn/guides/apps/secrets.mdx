机密数据用于保存应用需要的密码、令牌和凭据文件。创建一次后，可以在不同分组的应用中重复使用。

| 类型 | 使用方式 |
| --- | --- |
| 文本 | 作为环境变量传给应用，例如 API 令牌。 |
| 文件 | 通过 XConfig 作为只读文件挂载，例如凭据配置文件。 |

## 创建机密数据

创建、使用和删除机密数据需要 Operator 或 Admin；Reader 可以查看名称、类型和描述。

<Steps>

1. 打开侧栏的**机密数据**页面，点击**创建**。
2. 选择**文本**或**文件**，填写名称和可选描述。
3. 输入文本内容，或选择要上传的本地文件。
4. 点击**创建**，确认新机密数据出现在列表中。

</Steps>

内容不能为空，大小须小于 500 KiB；描述最多 64 字。文本支持多行，并保留空白和末尾换行。

创建后无法在平台查看、下载或修改内容。需要更换内容时，创建新的机密数据，再更新应用的选择。

名称和描述对有读取权限的账户可见；应用若把机密数据内容写入日志，日志中仍会出现这些内容。

## 在应用中使用

### 用作环境变量

<Steps>

1. 打开应用创建页或配置页，在环境变量中添加一项。
2. 填写变量名，例如 `API_TOKEN`，将来源切换为**机密数据**。
3. 选择已创建的文本机密数据，例如 `api-token`，确认该项。
4. 保存整个应用配置，等待部署完成，再验证应用能否正常访问对应服务。

</Steps>

### 挂载为文件

<Steps>

1. 在应用的文件与存储设置中添加配置文件。
2. 填写容器内文件路径，例如 `/etc/app/credentials.json`。
3. 将来源切换为**机密数据**，选择已创建的文件机密数据并确认。
4. 保存应用配置，等待部署完成，再确认应用能读取该路径。

</Steps>

文件以只读方式提供给应用，有本地数据卷的应用也可以使用。较大的配置内容适合使用文件机密数据。

## 更换与删除

<Steps>

1. 使用新名称创建替代内容，例如 `api-token-v2`。
2. 编辑需要更换的应用，将原来的选择改为新机密数据并保存。
3. 确认新部署工作正常后，回到机密数据列表删除不再使用的旧机密数据。

</Steps>

当前应用、运行任务或可回滚配置仍使用旧机密数据时，删除会被拒绝。先确认这些使用关系已结束，再删除。
