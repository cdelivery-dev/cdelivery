## 登记数据库

Admin 打开**依赖 → 新建依赖 → PostgreSQL**，填写名称，选择源 APP 并提供其 PostgreSQL DSN。源 APP 必须固定在已启用数据卷管理的服务器上，所有挂载均使用 ZFS 数据卷。登记后，同分组的 APP 可绑定此依赖。

## 演练数据卷

预览使用新的快照克隆，写入会丢弃，生产继续使用原卷。克隆共享存储池且不设配额，准备时至少需要 10% 可用空间。备份和恢复边界见[数据持久化](/docs/zh-cn/guides/apps/persistence/)。

如果更新的是数据库源 APP，CDelivery 也会检查直接绑定其已登记 PostgreSQL 依赖、且开启了发布检查的 APP。
