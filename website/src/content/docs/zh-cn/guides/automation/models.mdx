管理员打开 **Agent → 模型** 配置 AI。读取可用模型列表也属于管理员操作；普通用户使用管理员已经配置好的模型进行对话。

## 配置字段

| 字段 | 含义 |
| --- | --- |
| 提供商 | 选择对应的服务协议 |
| API 密钥 | 模型服务的访问凭据，保存后不回显 |
| 服务端点 | Ollama 和 OpenAI 兼容提供商需要填写 |
| 模型 | 提供商接受的准确模型标识 |

当前提供商选项包括 OpenAI、Anthropic、Gemini、DeepSeek、OpenRouter、Ollama 和 OpenAI 兼容服务。其他提供商的专用选项不接受自定义端点；需要兼容端点时使用相应兼容选项。

Ollama 不使用这里的 API 密钥字段。兼容服务和 Ollama 的端点必须能从运行 CDelivery 的环境访问；容器内的 `localhost` 不等于管理员电脑或宿主机上的任意服务。

## 设置步骤

1. 选择提供商。
2. 按该选项要求填写密钥或服务端点。
3. 使用界面的模型发现能力读取可用模型。
4. 选择或填写准确的模型名称。
5. 保存后，通过已绑定渠道发送一个只读状态查询。
6. 检查回复和实际查询结果，确认不仅能连接，也能执行所需工具调用。

模型出现在列表中，不保证它适合运维工具调用或能够稳定完成多步分析。应使用代表性只读问题验证能力，再决定是否用于自动值班。

## 保留与更换凭据

提供商和端点未变化时，界面允许按提示保留已有密钥。更换提供商或端点后，应重新配置对应凭据，不能假定原密钥继续适用。

保存不会返回密钥原文。需要更换时，从提供商重新取得有效凭据；不要把密钥粘贴到 Bot 对话中要求助手代为保管。

## 常见问题

| 现象 | 检查方向 |
| --- | --- |
| 模型列表读取失败 | 密钥、端点、出站网络和提供商权限 |
| 模型不存在 | 精确模型标识及当前账户可用范围 |
| 本地模型无法连接 | CDelivery 所在容器到端点的网络路径 |
| 能回复但工具调用失败 | 模型工具调用能力及服务协议兼容性 |
| 请求变慢或失败 | 提供商限制、服务负载、网络和模型错误 |

清除模型设置会影响 AI 对话和值班分析，但不等同于清除普通通知渠道。相关设置应分别核对。
