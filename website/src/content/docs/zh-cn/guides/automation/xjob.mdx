XJob 在应用上下文中按计划运行命令，适合周期性清理、同步或应用维护任务。创建、修改、手动执行和删除需要 Operator 或 Admin。

## 创建任务

1. 打开目标应用的 **XJob** 页面。
2. 创建任务，填写名称及执行命令。
3. 填写本轮结束后的等待间隔及执行超时，两者均必填，范围为 1–1440 分钟。
4. 保存后检查列表中的下次执行时间。
5. 对无破坏性的测试任务执行一次手动运行，确认结果。

每个应用最多配置 16 个任务。名称遵循平台名称规则；命令需要包含实际可执行程序，并能在应用镜像中运行。

## 命令示例

如果应用镜像包含 shell 和 `date`，可以先用以下只读命令验证执行链路：

```text
sh -c 'date -u'
```

需要执行实际维护脚本时，确认镜像包含脚本和所需工具。命令按参数解析，不会自动把管道、变量替换和重定向交给 shell。

任务运行的是独立任务容器，不能把它当作在某个正在运行的业务容器里执行交互式命令，也不能假定业务容器的临时文件会出现在任务中。

## 配置与执行环境

任务使用应用的镜像和相关运行配置。部署新镜像后，要确认任务命令及依赖仍然有效。需要访问同组服务时，使用服务的应用名称和容器端口。

涉及业务写入的任务应自行定义重复执行的行为。手动执行、失败后的再次执行或业务重试，都可能使同一工作被执行多次。

## 修改与删除

在任务详情中修改命令或计划并保存，再核对下次执行时间。正在执行时，界面会限制重复手动启动；先观察当前任务结果。

删除任务会取消该任务后续的调度配置，但不能撤销已经完成的业务操作。删除应用也会清理它的 XJob。

## 验证

成功退出应显示通过状态。失败时先查看错误，再在应用日志中选择对应 XJob 来源。执行超时按任务配置生效，由轮询发出停止请求，可能延迟；长期驻留服务应作为应用运行，而不是用定时任务维持。
