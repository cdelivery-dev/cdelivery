## 状态

| 状态 | 含义 |
| --- | --- |
| Pending | 等待执行 |
| Running | 正在检查 |
| Passed | 检查通过 |
| Failed | 检查失败，查看错误与日志 |
| Settled | 已结束，但没有可用的成功或失败结果 |

只有 Passed 表示通过。核对完成时间，避免把旧结果当作当前状态。

## 排查失败

打开最近的[应用日志](/docs/zh-cn/guides/observability/logs/application/)，选择 XHealth。一直等待时检查服务器资源和镜像拉取；长时间运行时检查超时及命令是否阻塞；执行失败时核对工具、变量和 Hurl 断言。

连接错误按目标排查：

| 目标 | 检查内容 |
| --- | --- |
| 域名 | 检查容器内的 DNS 解析、代理路由、HTTP/HTTPS 和证书信任 |
| 对外发布端口 | 服务器 IP 可达性、发布端口映射和防火墙 |
| 容器内端口 | 应用内部地址、分组网络、监听端口和启动状态 |

目标不存在或不明确时，核对应用配置及唯一内部端口映射。检查结果反映检查容器的访问情况，外部客户端可能经过不同的网络路径。

## 修改后验证

重新执行，确认新的 Passed 结果。断言应验证业务可用性，而非仅判断进程存在。

发布失败时，单独查看预览服务及其检查日志，勿混用线上 XHealth 结果。告警渠道见[通知设置](/docs/zh-cn/guides/automation/im/notifications/)。

目标和命令规则见 [XHealth 配置](/docs/zh-cn/guides/release-safety/xhealth/)。
