CDelivery 是自托管的应用运维平台。你提供服务器和容器镜像，通过控制台部署应用、配置访问入口、观察运行状态，并按需要接入自动检查、定时任务和 AI 助手。

## 开始使用

1. [安装前准备](/docs/zh-cn/getting-started/requirements/)：准备服务器地址、网络与访问条件。
2. [安装部署](/docs/zh-cn/getting-started/installation/)：启动平台并创建管理员。
3. [部署第一个应用](/docs/zh-cn/getting-started/first-app/)：部署 Hello 并验证访问。

## 核心概念

| 对象 | 含义 |
| --- | --- |
| 服务器 | 提供计算资源和本地存储的机器。 |
| 分组 | 组织应用，并提供组内通信网络。 |
| 应用 | 容器镜像、配置和期望运行方式的组合。 |
| 副本 | 应用实际运行的实例。 |

分组不隔离账户权限，访问范围见[角色与权限](/docs/zh-cn/administration/accounts/roles/)。需要保存业务数据时，先了解[数据持久化](/docs/zh-cn/guides/apps/persistence/)；副本和应用回滚不能替代备份。
