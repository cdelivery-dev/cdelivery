XConfig 將上傳的檔案作為設定交給應用程式容器，例如靜態首頁或應用程式啟動時讀取的設定檔案。它適合部署設定，不適合資料庫、上傳目錄或持續寫入的資料。

憑證檔案可以使用[檔案機密資料](/docs/zh-tw/guides/apps/secrets/)：新增設定檔時將來源切換為**機密資料**。下文的上傳和下載操作適用於一般設定檔。

## 使用條件

- 你具有 Operator 或 Admin 權限。
- 應用程式採用允許 XConfig 的無狀態部署方式。
- 已確定容器內需要讀取檔案的絕對路徑。
- 單個檔案非空，大小不超過 1,023,999 位元組。

使用本機資料掛載的有狀態應用程式不能同時使用一般 XConfig 檔案上傳。先根據[資料持久化](/docs/zh-tw/guides/apps/persistence/)選擇部署方式。

## 添加設定檔案

<Steps>

1. 打開應用程式建立頁或設定頁中的檔案與儲存設定。
2. 在設定檔案清單添加一項。
3. 填寫容器內目標檔案路徑，例如 Hello 應用程式的首頁 `/www/index.html`。
4. 選擇本地檔案，確認該行出現在待儲存清單。
5. 儲存整個應用程式設定，等待更新完成。

</Steps>

對話框中的確認只是完成本次表單編輯，仍需提交應用程式設定才能真正部署。目標應為檔案路徑，不能以斜槓結尾，也不能把目錄本身當作一個檔案掛載。

## 查看和保留已有檔案

已使用的設定會顯示平台記錄的檔案名稱，並提供下載入口。編輯其他應用程式設定時，保留原有行即可繼續引用已有檔案，無需每次重新上傳。

這些引用屬於當前應用程式使用的設定，不是供任意應用程式按名稱共享的全局設定庫。不要通過猜測其他應用程式的設定名稱來復用檔案。

修改內容和改變目標路徑的操作見[設定掛載與更新](/docs/zh-tw/guides/apps/xconfig/mounting/)。

## 設定、秘密和資料的邊界

| 內容 | 適合的方式 |
| --- | --- |
| 靜態頁面、應用程式啟動設定 | XConfig |
| 少量執行參數 | 環境變數 |
| 資料庫檔案、業務上傳 | 持久化資料卷 |
| 儲存庫認證 | 映像檔驗證資訊欄位 |

設定檔案可能通過共享讀取能力被查看或下載，不要假設檔案中的密碼會被自動脫敏。

XConfig 也不是長期備份庫。保留你自己的設定源檔案或版本庫；刪除引用後，平台可能清理不再被執行資源使用的設定。

## 上傳失敗時

檢查檔案是否為空或超過大小限制、目標路徑是否合法、是否與其他掛載衝突，以及應用程式是否已選擇本機資料模式。儲存後核對應用程式實際讀取的檔案路徑。
