應用程式將映像檔、啟動參數、網路、資源和存儲組合為期望的執行設定。控制台負責提交和展示這些設定，實際執行結果還需要通過副本狀態、日誌和業務存取確認。

## 操作前的選擇

| 需要決定的事項 | 為什麼要提前考慮 |
| --- | --- |
| 所屬分組 | 決定應用程式組織及組內通信，控制台不提供應用程式改名或移動分組操作 |
| 是否儲存業務資料 | 本地資料掛載需要在建立時選擇，不能在普通應用程式建立後直接切換為該模式 |
| 映像檔與啟動方式 | 需要知道映像檔監聽連接埠、啟動指令及必需環境變數 |
| 存取入口 | 內部通信、直接發佈連接埠、網域存取是不同的設定 |
| 資源與副本 | 每個副本都需要資源，更新期間也可能需要額外容量 |

Reader 可以查看共享資訊。建立、修改、重啟和刪除應用程式需要 Operator 或 Admin；建立分組與管理伺服器資源需要 Admin。
