應用程式將映像檔、啟動參數、網路、資源和存儲組合為期望的執行設定。控制台負責提交和展示這些設定，實際執行結果還需要通過副本狀態、日誌和業務存取確認。

## 操作前的選擇

| 需要決定的事項 | 為什麼要提前考慮 |
| --- | --- |
| 所屬分組 | 決定應用程式組織及組內通信，控制台不提供應用程式改名或移動分組操作 |
| 是否儲存業務資料 | 本地資料掛載需要在建立時選擇，不能在普通應用程式建立後直接切換為該模式 |
| 映像檔與啟動方式 | 需要知道映像檔監聽連接埠、啟動指令及必需環境變數 |
| 存取入口 | 內部通信、直接發佈連接埠、網域存取是不同的設定 |
| 資源與副本 | 每個副本都需要資源，更新期間也可能需要額外容量 |

Reader 可以查看共享資訊。建立、修改、重啟和刪除應用程式需要 Operator 或 Admin；建立分組與管理伺服器資源需要 Admin。

## 預設行為與驗證

從空白表單建立時，應用程式預設固定一個副本，使用映像檔預設指令和宿主機日誌設定；沒有額外資源預留或調度標籤。預設更新策略為全部副本並行、先停止舊副本、觀察 60 秒、失敗比例閾值 0，失敗動作是回復。業務有連續服務要求時，建立後應檢查[更新策略](/docs/zh-tw/guides/release-safety/update-strategy/)。

儲存成功後先看實際副本，再看應用程式日誌，最後驗證用戶端請求。設定無變化時，重複儲存不會強制重新部署；需要替換執行容器時使用重啟操作。

設定頁面中的環境變數和檔案內容不應被視作個人私密存儲。平台只對明確識別的秘密字段脫敏，其他共享設定可能被具備讀取權限的帳戶看到。

需要業務級檢查時設定 [XHealth](/docs/zh-tw/guides/release-safety/xhealth/)；需要在推廣新設定前驗證候選實例時，再瞭解 [Guardian](/docs/zh-tw/guides/release-safety/)。
