用 XHealth 驗證業務回應，用更新策略控制副本替換，用 Guardian 驗證候選設定；需要恢復已推廣的設定時使用回滾。

## 按任務查找

<CardGrid>

<Card title="設定健康檢查" href="/docs/zh-tw/guides/release-safety/xhealth/" icon="ph:heartbeat">
  使用 Hurl 或自訂指令檢查應用程式回應，設定目標、執行間隔和發佈驗證。
</Card>

<Card title="更新策略" href="/docs/zh-tw/guides/release-safety/update-strategy/" icon="ph:arrows-clockwise">
  設定副本更新順序、並行度、觀察窗口和失敗動作，並評估容量與業務影響。
</Card>

<Card title="發佈驗證（Guardian）" href="/docs/zh-tw/guides/release-safety/guardian/" icon="ph:shield-check">
  先驗證候選設定再推廣到正式應用程式，理解失敗、重試、跳過和取消的含義。
</Card>

<Card title="回復與失敗處理" href="/docs/zh-tw/guides/release-safety/rollback/" icon="ph:arrow-u-up-left">
  區分取消候選發佈和恢復上一份設定，驗證回復後的副本及業務狀態。
</Card>

</CardGrid>
