## 狀態

| 狀態 | 含義 |
| --- | --- |
| Pending | 等待執行 |
| Running | 正在檢查 |
| Passed | 檢查通過 |
| Failed | 檢查失敗，查看錯誤與日誌 |
| Settled | 已結束，但沒有可用的成功或失敗結果 |

只有 Passed 表示通過。核對完成時間，避免把舊結果當作目前狀態。

## 排查失敗

開啟最近的[應用程式日誌](/docs/zh-tw/guides/observability/logs/application/)，選擇 XHealth。一直等待時檢查伺服器資源和映像檔拉取；長時間執行時檢查逾時及指令是否阻塞；執行失敗時核對工具、變數和 Hurl 斷言。

連線錯誤按目標排查：

| 目標 | 檢查內容 |
| --- | --- |
| 網域 | 檢查容器內的 DNS 解析、代理路由、HTTP/HTTPS 和憑證信任 |
| 對外連接埠 | 伺服器 IP 可達性、對外連接埠映射和防火牆 |
| 容器內連接埠 | 應用程式內部位址、分組網路、監聽連接埠和啟動狀態 |

目標不存在或不明確時，核對應用程式設定及唯一內部連接埠映射。檢查結果反映檢查容器的存取情況，外部用戶端可能經過不同的網路路徑。

## 修改後驗證

重新執行，確認新的 Passed 結果。斷言應驗證業務可用性，而非僅判斷程序存在。

發布失敗時，單獨查看預覽服務及其檢查日誌，勿混用線上 XHealth 結果。告警管道見[通知設定](/docs/zh-tw/guides/automation/im/notifications/)。

目標和指令規則見 [XHealth 設定](/docs/zh-tw/guides/release-safety/xhealth/)。
