已有企業憑證或使用其他簽發流程時，可以在 Pingress 中上傳憑證。上傳、替換和移除需要 Admin 權限。

## 準備檔案

準備 PEM 格式的憑證鏈與對應私鑰。憑證需要覆蓋目標網域，處於有效期內，並與私鑰匹配。憑證鏈應包含用戶端建立信任所需的中間憑證。

私鑰不是公開憑證內容。不要把私鑰放入應用程式日誌、工單、聊天記錄或儲存庫；分享故障資訊時只提供必要的憑證元資料。

## 上傳步驟

1. 在應用程式中儲存目標網域並開啟 HTTPS。
2. 打開 **Pingress → 憑證**，進入該網域的憑證詳情。
3. 按表單要求上傳或填寫憑證鏈與私鑰。
4. 儲存後檢查憑證來源和到期時間。
5. 從實際用戶端使用網域存取 HTTPS，檢查信任鏈、網域匹配和業務回應。

憑證檔案上傳成功與瀏覽器信任是兩個檢查環節。用戶端缺少對應根憑證時，內部 CA 簽發的憑證仍可能顯示不受信任。

## 替換和續期

手動憑證不會由自動續期流程更新。到期前應通過你的簽發流程取得新憑證，並在同一網域詳情頁重新上傳完整憑證鏈和匹配的私鑰。

替換後驗證新到期時間及用戶端實際收到的憑證。前置 CDN 或其他 TLS 代理可能向用戶端展示它自己的憑證，排查時應明確正在檢查哪一層。

## 移除憑證

移除前確認該網域是否仍提供 HTTPS，以及是否已經準備好替代憑證。刪除憑證不是關閉 DNS，也不是刪除應用程式路由。

需要改回自動憑證時，確認[自動簽發條件](/docs/zh-tw/guides/networking/automatic-certificates/)已滿足，並觀察後續簽發結果。不要假設移除手動憑證後立刻就有新憑證可用。

## 常見錯誤

| 問題 | 處理方式 |
| --- | --- |
| PEM 無法解析 | 檢查檔案邊界、編碼及是否選錯檔案 |
| 私鑰不匹配 | 使用與憑證公鑰對應的私鑰重新提交 |
| 網域不匹配 | 檢查憑證包含的網域，不能只依據檔案名稱判斷 |
| 已過期或尚未生效 | 檢查憑證有效期及伺服器時間 |
| 瀏覽器報告鏈不完整 | 補齊正確的中間憑證鏈 |
| 上傳後用戶端仍見舊憑證 | 核對存取地址、入口實例及前置代理 |

憑證正常但請求失敗時，繼續檢查[網域與路由](/docs/zh-tw/guides/networking/routing/)和[存取日誌](/docs/zh-tw/guides/observability/logs/access/)。
