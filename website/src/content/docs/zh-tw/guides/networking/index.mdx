應用程式網路可以分為三個層次：組內應用程式通信、直接發佈連接埠、通過 Pingress 使用網域。先選擇存取方式，再設定相應的伺服器、防火牆和憑證。

## 選擇入口

| 存取需求 | 使用方式 | 示例 |
| --- | --- | --- |
| 同分組應用程式互相呼叫 | 應用程式名稱與容器連接埠 | `http://backend:8080` |
| 直接存取某個應用程式連接埠 | 發佈連接埠 | `http://SERVER_IP:8080` |
| 使用網站網域及 HTTPS | Pingress 與網域路由 | `https://app.example.com` |

應用程式通過 Pingress 暴露容器連接埠時，不需要為了同一個入口再單獨發佈該連接埠。資料庫等內部服務也不必為了組內通信暴露公網連接埠。

## 排查存取失敗

沿著“用戶端 → DNS → Pingress → 應用程式容器連接埠”逐段檢查。應用程式副本執行但外部存取失敗時，先區分是連接、TLS、路由還是業務回應問題。

使用[存取日誌](/docs/zh-tw/guides/observability/logs/access/)檢查請求是否到達入口及匹配到哪個應用程式。IPv6、用戶端地址和安裝後網路調整見[常見問題](/docs/zh-tw/guides/networking/faq/)。
