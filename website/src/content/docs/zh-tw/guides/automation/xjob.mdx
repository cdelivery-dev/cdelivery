XJob 在應用程式上下文中按計劃執行指令，適合週期性清理、同步或應用程式維護任務。建立、修改、手動執行和刪除需要 Operator 或 Admin。

## 建立任務

1. 打開目標應用程式的 **XJob** 頁面。
2. 建立任務，填寫名稱及執行指令。
3. 填寫本輪結束後的等待間隔及執行逾時，兩者均必填，範圍為 1–1440 分鐘。
4. 儲存後檢查清單中的下次執行時間。
5. 對無破壞性的測試任務執行一次手動執行，確認結果。

每個應用程式最多設定 16 個任務。名稱遵循平台名稱規則；指令需要包含實際可執行程序，並能在應用程式映像檔中執行。

## 指令示例

如果應用程式映像檔包含 shell 和 `date`，可以先用以下唯讀指令驗證執行連線路徑：

```text
sh -c 'date -u'
```

需要執行實際維護腳本時，確認映像檔包含腳本和所需工具。指令按參數解析，不會自動把管道、變數替換和重定向交給 shell。

任務執行的是獨立任務容器，不能把它當作在某個正在執行的業務容器里執行交互式指令，也不能假定業務容器的臨時檔案會出現在任務中。

## 設定與執行環境

任務使用應用程式的映像檔和相關執行設定。部署新映像檔後，要確認任務指令及依賴仍然有效。需要存取同組服務時，使用服務的應用程式名稱和容器連接埠。

涉及業務寫入的任務應自行定義重複執行的行為。手動執行、失敗後的再次執行或業務重試，都可能使同一工作被執行多次。

## 修改與刪除

在任務詳情中修改指令或計劃並儲存，再核對下次執行時間。正在執行時，界面會限制重複手動啟動；先觀察當前任務結果。

刪除任務會取消該任務後續的調度設定，但不能撤銷已經完成的業務操作。刪除應用程式也會清理它的 XJob。

## 驗證

成功退出應顯示通過狀態。失敗時先查看錯誤，再在應用程式日誌中選擇對應 XJob 來源。執行逾時依任務設定生效，由輪詢發出停止請求，可能延遲；長期駐留服務應作為應用程式執行，而不是用定時任務維持。
