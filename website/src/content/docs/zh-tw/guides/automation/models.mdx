管理員打開 **Agent → 模型** 設定 AI。讀取可用模型清單也屬於管理員操作；普通使用者使用管理員已經設定好的模型進行對話。

## 設定欄位

| 欄位 | 含義 |
| --- | --- |
| 供應商 | 選擇對應的服務協議 |
| API 金鑰 | 模型服務的存取驗證資訊，儲存後不回顯 |
| 服務位址 | Ollama 和 OpenAI 相容供應商需要填寫 |
| 模型 | 供應商接受的準確模型標識 |

當前供應商選項包括 OpenAI、Anthropic、Gemini、DeepSeek、OpenRouter、Ollama 和 OpenAI 相容服務。其他供應商的專用選項不接受自訂服務位址；需要相容服務位址時使用相應相容選項。

Ollama 不使用這裡的 API 金鑰欄位。相容服務和 Ollama 的服務位址必須能從執行 CDelivery 的環境存取；容器內的 `localhost` 不等於管理員電腦或宿主機上的任意服務。

## 設定步驟

<Steps>

1. 選擇供應商。
2. 按該選項要求填寫金鑰或服務位址。
3. 使用介面的模型發現能力讀取可用模型。
4. 選擇或填寫準確的模型名稱。
5. 儲存後，通過已綁定渠道發送一個唯讀狀態查詢。
6. 檢查回覆和工具呼叫結果；用於自動值班前，再用具代表性的唯讀問題驗證。

</Steps>

## 保留與更換驗證資訊

供應商和服務位址未變化時，介面允許按提示保留已有金鑰。更換供應商或服務位址後，應重新設定對應驗證資訊，不能假定原金鑰繼續適用。

儲存不會回傳金鑰原文。需要更換時，從供應商重新取得有效驗證資訊；不要把金鑰貼上到 Bot 對話中要求助手代為保管。

## 常見問題

| 現象 | 檢查方向 |
| --- | --- |
| 模型清單讀取失敗 | 金鑰、服務位址、出站網路和供應商權限 |
| 模型不存在 | 精確模型標識及當前帳戶可用範圍 |
| 本地模型無法連接 | CDelivery 所在容器到服務位址的網路路徑 |
| 能回覆但工具呼叫失敗 | 模型工具呼叫能力及服務協議相容性 |
| 請求變慢或失敗 | 供應商限制、服務負載、網路和模型錯誤 |

清除模型設定會影響 AI 對話和值班分析，但不等同於清除普通通知渠道。相關設定應分別核對。
