管理員打開 **Agent → 模型** 設定 AI。讀取可用模型清單也屬於管理員操作；普通使用者使用管理員已經設定好的模型進行對話。

## 設定字段

| 字段 | 含義 |
| --- | --- |
| 提供商 | 選擇對應的服務協議 |
| API 金鑰 | 模型服務的存取憑據，儲存後不回顯 |
| 服務端點 | Ollama 和 OpenAI 兼容提供商需要填寫 |
| 模型 | 提供商接受的準確模型標識 |

當前提供商選項包括 OpenAI、Anthropic、Gemini、DeepSeek、OpenRouter、Ollama 和 OpenAI 兼容服務。其他提供商的專用選項不接受自訂端點；需要兼容端點時使用相應兼容選項。

Ollama 不使用這裡的 API 金鑰字段。兼容服務和 Ollama 的端點必須能從執行 CDelivery 的環境存取；容器內的 `localhost` 不等於管理員電腦或宿主機上的任意服務。

## 設定步驟

1. 選擇提供商。
2. 按該選項要求填寫金鑰或服務端點。
3. 使用界面的模型發現能力讀取可用模型。
4. 選擇或填寫準確的模型名稱。
5. 儲存後，通過已綁定渠道發送一個唯讀狀態查詢。
6. 檢查回復和實際查詢結果，確認不僅能連接，也能執行所需工具呼叫。

模型出現在清單中，不保證它適合維運工具呼叫或能夠穩定完成多步分析。應使用代表性唯讀問題驗證能力，再決定是否用於自動值班。

## 保留與更換憑據

提供商和端點未變化時，界面允許按提示保留已有金鑰。更換提供商或端點後，應重新設定對應憑據，不能假定原金鑰繼續適用。

儲存不會回傳金鑰原文。需要更換時，從提供商重新取得有效憑據；不要把金鑰粘貼到 Bot 對話中要求助手代為保管。

## 常見問題

| 現象 | 檢查方向 |
| --- | --- |
| 模型清單讀取失敗 | 金鑰、端點、出站網路和提供商權限 |
| 模型不存在 | 精確模型標識及當前帳戶可用範圍 |
| 本地模型無法連接 | CDelivery 所在容器到端點的網路路徑 |
| 能回復但工具呼叫失敗 | 模型工具呼叫能力及服務協議兼容性 |
| 請求變慢或失敗 | 提供商限制、服務負載、網路和模型錯誤 |

清除模型設定會影響 AI 對話和值班分析，但不等同於清除普通通知渠道。相關設定應分別核對。
