## 建議的初始化順序

安裝並建立首個 Admin 後，先核對伺服器地址和狀態，再建立分組與應用程式。需要多人協作時，為每個人建立獨立帳戶並分配適當角色。隨後根據需要設定網域、觀測、消息渠道和 AI。

分組不隔離帳戶權限，伺服器標籤也不提供資料複製。更改調度或刪除資源前，應核對依賴這些資源的應用程式和平台組件。

## 管理操作如何驗收

儲存成功表示操作請求已完成或已提交，容器更新、加入伺服器和後台採集仍可能需要時間。操作後分別檢查資源清單、實際執行狀態、事件和存取結果。備份與恢復還需要驗證業務資料，不能只看容器處於執行中。
