分組用於組織應用程式，並為組內應用程式提供共同的通信網路。可以按項目或環境命名，例如 `demo`、`production`。分組不是帳戶權限邊界，各角色可讀取其允許的全部分組共享資訊。

## 建立和使用

1. Admin 打開分組清單並建立分組。
2. 填寫 1–16 位名稱，使用小寫字母、數字或連字符，不以連字符開頭或結尾，不使用保留名稱。
3. 按需填寫說明，最多 256 個字符。
4. 建立應用程式時選擇該分組。
5. 檢查應用程式清單和[組內通信](/docs/zh-tw/guides/networking/connectivity/)。

應用程式名稱在平台內唯一，不能通過換一個分組復用已存在的應用程式名稱。控制台建立後不提供重命名分組或移動應用程式的操作，因此建立前確定用途和名稱。

## 維護說明

說明用於記錄用途、環境或負責人，不影響調度與權限。建立分組時若網路已建立但說明儲存失敗，分組可能已經存在；刷新清單後補充說明，無需重複建立。

更改說明不會重建應用程式。通過 API 更新時，省略說明表示保持原值，顯式清空才會移除說明。

## 刪除與排障

先刪除或處理組內應用程式和網路引用，再刪除分組。應用程式刪除後容器退出是異步的，立即刪除分組可能提示仍被佔用；確認任務退出後重試。

刪除分組不會自動清理業務資料卷。需要保留資料時，在[資料卷管理](/docs/zh-tw/administration/nodes/volumes/)中記錄所在伺服器和卷名。

若出現名稱衝突，檢查現有分組；若組內應用程式無法互訪，檢查是否屬於同一分組、目標容器連接埠、監聽地址和伺服器間網路。
