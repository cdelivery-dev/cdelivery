標籤把具備相同用途的伺服器組織成可選擇的執行範圍。例如，為兩台應用程式伺服器添加 `web`，為存儲機器添加 `storage`。

## 添加標籤

1. 以 Admin 從伺服器清單打開目標機器。
2. 添加所需標籤並儲存。
3. 在其他同類伺服器上使用相同標籤。
4. 在應用程式的[伺服器選擇](/docs/zh-tw/guides/apps/placement/)或組件設定中選擇該標籤。
5. 檢查實際任務落點和資源是否滿足需求。

每台伺服器最多 32 個調度標籤。標籤使用 1–16 個小寫字母、數字或連字符，不能以連字符開頭或結尾，也不能使用保留名稱。標籤表達成員關係，不提供任意鍵值查詢或複雜條件表達式。

## 變更的影響

同一個標籤可以屬於多台機器。刪除標籤會改變依賴該標籤的任務可選範圍；如果沒有可用機器，任務可能無法啟動。添加標籤之前也應確認該機器的容量、映像檔架構、網路和資料條件。

固定伺服器的應用程式不因相同標籤而遷移。標籤不會同步本地卷；需要本地資料的工作負載應遵循[有狀態應用程式](/docs/zh-tw/guides/apps/persistence/stateful/)的部署方式。

## 驗證與排障

儲存後重新打開伺服器檢查標籤，再查看應用程式的實際副本分布。若任務一直等待，檢查是否至少有一台 Ready、可調度且資源充足的匹配機器，以及每台伺服器的副本上限。

通過 API 更新標籤時，`labels` 是完整替換集合，空數組會清空平台調度標籤。先讀取當前集合再修改，避免把需要保留的標籤遺漏。
