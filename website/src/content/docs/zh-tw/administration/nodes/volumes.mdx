資料卷屬於具體伺服器。同名資料卷出現在不同伺服器上時，也不是同一份資料。刪除應用程式會保留資料卷，刪除資料卷才會移除對應的本機資料。

## 啟用與建立

<Steps>

1. 以 Admin 啟用資料卷管理元件；該元件使用獨立的 cdelivery-agent 映像檔。
2. 打開伺服器詳情中的資料卷頁面。
3. 建立資料卷，填寫名稱和可選說明。名稱遵循平台命名規則，說明最多 256 個字元。
4. 建立[有狀態應用程式](/docs/zh-tw/guides/apps/persistence/stateful/)，選擇同一伺服器，將資料卷掛載到映像檔要求的資料目錄。
5. 寫入測試資料並重新啟動應用程式，確認資料仍存在。

</Steps>

## 查看容量

清單可查詢資料卷大小，並顯示伺服器的總空間與可用空間。大小查詢需要遍歷資料，較大的資料卷可能花費更長時間；未查詢或未回傳大小不等於資料卷為空。

平台內部保留的資料卷不作為一般業務資料卷管理。資料卷說明用於記錄用途。

## 刪除與排障

<Aside type="caution">
刪除資料卷會移除對應的本機資料；刪除應用程式會保留資料卷。
</Aside>

如果資料卷說明儲存失敗，重新整理清單後為已建立的資料卷補充說明。

刪除前確認相關應用程式已停止使用資料卷，並有可恢復的業務備份。被容器佔用時，先檢查引用和非同步退出狀態，再重新刪除。

無法列出資料卷時，檢查目標伺服器是否在線、資料卷管理元件是否啟用並正常執行。停用資料卷管理元件會影響管理能力，不會自動刪除業務資料卷。資料卷不存在時核對伺服器 ID 和資料卷名；不要在另一台機器新建同名資料卷來代替復原資料。

資料遷移、資料庫一致性備份和跨伺服器複製需要由業務儲存方案完成。繼續閱讀[資料持久化](/docs/zh-tw/guides/apps/persistence/)。
