伺服器清單展示機器名稱、角色、狀態、CPU、內存及調度標籤。主機名可能重複，判斷具體機器時同時核對地址和伺服器 ID。

## 加入伺服器

1. 以 Admin 打開伺服器清單，選擇 Worker 或 Manager 的加入指令。
2. 在目標伺服器檢查[安裝要求](/docs/zh-tw/getting-started/requirements/)，確認它能存取管理地址和伺服器間通信連接埠。
3. 在目標機器執行頁面給出的指令。指令中包含加入憑證，不要公開分享。
4. 刷新清單，確認新伺服器出現、狀態 Ready，並核對角色和地址。
5. 按用途添加[標籤](/docs/zh-tw/administration/nodes/labels/)，再部署應用程式。

Worker 承載工作負載；Manager 還參與管理。加入憑證有效 30 分鐘，可在有效期內復用。平台重啟後應重新獲取；簽發者權限變化也可能使憑證失效。過期時刷新頁面生成新指令，不要反復嘗試舊憑證。

## 理解狀態

| 字段 | 含義 |
| --- | --- |
| Ready / Down / Disconnected | 當前執行或連接狀態 |
| Active | 可接收調度 |
| Pause | 不接收新的任務 |
| Drain | 排空任務的調度狀態 |
| Reachable / Unreachable | Manager 的管理連接狀態 |
| 採集器告警 | 觀測報告可能不新鮮，需單獨檢查採集連線路徑 |

狀態展示不意味著控制台提供所有狀態切換操作。資源總量也不等於當前剩餘容量，結合[伺服器指標](/docs/zh-tw/guides/observability/metrics/server/)查看。

## 移除伺服器

當前移除操作不替你完成應用程式遷移、資料備份或伺服器排空。先檢查固定在該伺服器上的有狀態應用程式、資料卷和平台組件，以及其餘伺服器的容量。Manager 的移除還應保持管理能力可用。

確認依賴已處理後再刪除。移除記錄不擦除原機器上的本地卷，也不能確認離線機器上的容器已經退出。重新加入後伺服器 ID 可能變化，應重新核對固定伺服器設定和標籤。

加入失敗時依次檢查地址、憑證有效期、Docker 狀態、連接埠與防火牆；不要只根據瀏覽器能打開控制台判斷伺服器間通信正常。
