安裝初始化建立首個 Admin。後續使用者由 Admin 在設定的使用者管理中建立，團隊成員應使用獨立帳戶。

## 建立與編輯

1. 打開使用者管理，填寫姓名、郵箱、初始密碼和角色。
2. 確認郵箱唯一且屬於使用者，角色按[權限表](/docs/zh-tw/administration/accounts/roles/)選擇。
3. 儲存後通過適當方式交付初始密碼。
4. 讓使用者登入、修改密碼並設定兩步驟驗證。
5. 如需通知，由使用者完成個人消息綁定和訂閱。

管理員可修改使用者姓名、郵箱和角色。郵箱是登入標識，也影響郵件通知和郵件入站身份；變更前確認收件地址由正確人員控制。

## 重置登入

重置密碼後，該使用者全部瀏覽器會話立即失效，需要使用新密碼重新登入。API 金鑰與密碼獨立，仍保持有效；若懷疑金鑰洩露，不能只改密碼。

重置兩步驟驗證是獨立操作，不因普通密碼重置自動完成。丟失驗證器時，先核對人員身份，再重置兩步驟驗證，由使用者重新綁定。

## 刪除與交接

刪除使用者會使其會話和 API 金鑰無法繼續認證。刪除不會替你刪除共享應用程式、撤銷外部服務商憑證或回收已導出的資料。先完成業務交接，再刪除帳戶。

Admin 不能刪除自己或把自己降級。需要變更當前管理員時，先由另一位 Admin 接手；失去全部管理存取時參閱[恢復管理存取](/docs/zh-tw/administration/platform/recovery/)。

建立失敗時檢查郵箱重複與表單校驗；使用者反饋“權限不足”時核對實時角色以及所用 API 金鑰的角色上限。
