個人帳戶集中管理姓名、界面語言、主題、密碼、兩步驟驗證、消息綁定和 API 金鑰。所有角色都可以管理自己的帳戶；郵箱和角色變更由管理員處理。

## 修改密碼

打開帳戶的密碼頁面，輸入當前密碼和新密碼並儲存。密碼修改後，所有瀏覽器會話都會失效，包括當前會話，需重新登入。API 金鑰不受改密影響；需要停止外部工具時單獨撤銷金鑰。

如果不記得當前密碼，請聯繫 Admin 重置；管理員也無法登入時使用[恢復管理存取](/docs/zh-tw/administration/platform/recovery/)。

## 兩步驟驗證

1. 打開兩步驟驗證頁面，用驗證器掃描二維碼或輸入顯示的金鑰。
2. 輸入當前密碼和驗證器的六位代碼。
3. 提交後確認頁面顯示已啟用。
4. 在新的登入會話中驗證密碼和動態代碼均可正常使用。

僅掃描二維碼不算啟用，必須完成提交驗證。二維碼和金鑰可用於生成登入代碼，不要公開分享。代碼持續失敗時檢查設備時間、帳戶條目和代碼是否已經過期。

關閉兩步驟驗證需要當前密碼和當前代碼。丟失驗證器時由管理員重置，或通過主機救援恢復；不要假定平台提供備用恢復碼。

## 偏好與連接

界面支援八種語言，主題可選擇明暗或跟隨系統。消息平台綁定填寫自己的不可變使用者 ID，通知開關獨立控制是否接收告警。具體 ID 獲取方式見[消息渠道](/docs/zh-tw/guides/automation/im/)。

API 金鑰只在建立時顯示一次，適合外部工具，不要把瀏覽器 Cookie 當作長期集成憑證。參閱 [API 與 MCP](/docs/zh-tw/guides/automation/api-mcp/)。
