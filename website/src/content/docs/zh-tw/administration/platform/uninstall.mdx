解除安裝會刪除平台管理資源、應用程式定義、帳戶和憑證。腳本保留所有資料卷及卷說明，但保留卷不等於能夠一鍵恢復原平台。

## 準備與預覽

在管理伺服器上準備 Docker CLI 和 jq，選擇本機 Docker Unix socket。先記錄應用程式設定、映像檔、卷與伺服器的對應關係，並完成業務資料備份。解除安裝期間停止建立或重建資源。

下載官網腳本後先預覽：

```sh
curl -fsSLo /tmp/cdelivery-uninstall.sh https://cdelivery.dev/uninstall.sh
sh /tmp/cdelivery-uninstall.sh
```

不帶參數只列出選中的服務、設定、憑證、網路和平台調度標籤，不刪除資源。核對當前 Docker 地址與資源名單，避免在錯誤部署上執行。

## 執行解除安裝

確認預覽符合預期後執行：

```sh
sh /tmp/cdelivery-uninstall.sh --yes
```

腳本先停止主程序，再刪除帶有平台管理標記的資源。它不會解除安裝 Docker、擦除本地卷或替你刪除外部 DNS、對象存儲和服務商帳戶。

## 驗證與失敗處理

檢查所列管理資源是否已移除，並確認要保留的資料卷仍在原伺服器。容器清理是異步的；離線伺服器上的容器是否退出無法在此時確認，需要恢復連接後單獨核查。

某一步刪除失敗時，腳本停止並提示錯誤。先修復佔用、連接或權限問題，再重新執行 `--yes`。不要在解除安裝尚未結束時重新安裝或手工建立同名資源。

若還要刪除業務卷，必須另行確認資料不再需要。重新安裝會建立新的管理資料，原卷的恢復和重新掛載需要根據業務備份與記錄完成。
