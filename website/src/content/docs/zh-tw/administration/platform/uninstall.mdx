解除安裝會刪除平台管理資源、應用程式定義、帳戶和憑證，保留所有資料卷及資料卷說明。
</Aside>

## 解除安裝

在管理伺服器上準備 Docker CLI 和 jq，選擇本機 Docker Unix socket。先記錄應用程式設定、映像檔、資料卷與伺服器的對應關係，並完成業務資料備份。解除安裝期間停止建立或重建資源。

在互動式終端中執行：

```sh
curl -fsSL https://cdelivery.dev/uninstall.sh | sh
```

核對腳本顯示的 Docker 位址和待刪除資源，輸入 `y` 或 `Y` 並按 Enter 確認。直接按 Enter、輸入其他內容或按 Ctrl+C 均可取消。沒有待刪除資源時，腳本直接結束，無需確認。

腳本先停止主程式，再刪除帶有平台管理標記的資源。回報完成前，最多等待 120 秒，確認受管網路從本機 Docker 網路清單中消失；逾時則列出剩餘網路並以錯誤結束。它不會解除安裝 Docker、擦除本機資料卷或替你刪除外部 DNS、物件儲存和服務商帳戶。

## 驗證與失敗處理

檢查所列管理資源是否已移除，並確認要保留的資料卷仍在原伺服器。容器清理是非同步的；離線伺服器上的容器是否退出無法在此時確認，需要恢復連接後單獨核查。

某一步刪除失敗時，腳本停止並提示錯誤。先修復佔用、連接或權限問題，再重新執行同一命令，重新預覽並確認。不要在解除安裝尚未結束時重新安裝或手工建立同名資源。

若還要刪除業務資料卷，必須另行確認資料不再需要。重新安裝會建立新的管理資料，原資料卷的恢復和重新掛載需要根據業務備份與記錄完成。
