安裝後可通過伺服器地址的 9000 連接埠存取控制台。Admin 可以在**設定 → CDelivery**中設定平台自己的網域，例如 `ops.example.com`。

## 設定網域

1. 啟用 Pingress，並選擇能接收存取的伺服器。
2. 將網域的 A/AAAA 記錄指向對應入口；僅保留實際可用的地址。
3. 確認 80/443 連接埠、防火牆和上游代理設定。
4. 在 CDelivery 設定填寫網域，不包含協議、連接埠或路徑。
5. 按需勾選 HTTPS 並儲存。
6. 在新標籤頁存取新網域，驗證登入、頁面和 API。

HTTPS 需要有效的[自動憑證](/docs/zh-tw/guides/networking/automatic-certificates/)或[自訂憑證](/docs/zh-tw/guides/networking/custom-certificates/)。只勾選 HTTPS 不會替代 DNS 與憑證準備。

## 切換與撤銷

切換網域之前保留當前可用的管理連接，驗證新入口後再調整外部引用。瀏覽器 Cookie 按存取主機區分，更換網域後可能需要重新登入；MCP 用戶端和自動化腳本也需更新實例地址。

清空網域並儲存會移除平台網域路由，不會替你刪除 DNS 記錄。設定平台網域不會自動關閉原有 9000 連接埠；如需限制其存取，在主機或網路層設定相應規則。

## 排障

無法解析時檢查 DNS；TLS 失敗時檢查憑證網域、有效期和完整鏈；出現網關錯誤時檢查平台服務和入口伺服器。若網域不可用但原管理連接埠仍可達，可從原入口修正設定。

應用程式自己的業務網域在[網域與路由](/docs/zh-tw/guides/networking/routing/)中管理，不應把平台管理網域重複用於其他衝突路由。
