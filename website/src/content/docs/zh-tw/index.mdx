CDelivery 是自托管的應用程式維運平台。你提供伺服器和容器映像檔，通過控制台部署應用程式、設定存取入口、觀察執行狀態，並按需要接入自動檢查、定時任務和 AI 助手。

## 開始使用

1. [安裝前準備](/docs/zh-tw/getting-started/requirements/)：準備伺服器地址、網路與存取條件。
2. [安裝部署](/docs/zh-tw/getting-started/installation/)：啟動平台並建立管理員。
3. [部署第一個應用程式](/docs/zh-tw/getting-started/first-app/)：部署 Nginx 並驗證存取。

## 核心概念

| 對象 | 含義 |
| --- | --- |
| 伺服器 | 提供計算資源和本地儲存的機器。 |
| 分組 | 組織應用程式，並提供組內通信網路。 |
| 應用程式 | 容器映像檔、設定和預期執行方式的組合。 |
| 副本 | 應用程式實際執行的實例。 |

分組不隔離帳戶權限，存取範圍見[角色與權限](/docs/zh-tw/administration/accounts/roles/)。需要保存業務資料時，先瞭解[資料持久化](/docs/zh-tw/guides/apps/persistence/)；副本和應用程式回復不能替代備份。
