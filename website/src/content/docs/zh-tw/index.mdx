CDelivery 幫助你部署應用程式、管理伺服器，並通過檢查、日誌、指標和自動化處理日常維運。文件按任務分層組織，功能概覽下提供設定、驗證、限制和排障說明。

## 快速開始

第一次使用時，按以下順序完成一條可驗證的部署流程：

1. [認識 CDelivery](/docs/zh-tw/getting-started/introduction/)：理解平台組成與主要對象。
2. [安裝要求](/docs/zh-tw/getting-started/requirements/)：準備伺服器、網路與存取條件。
3. [安裝](/docs/zh-tw/getting-started/installation/)：啟動平台並建立管理員。
4. [部署第一個應用程式](/docs/zh-tw/getting-started/first-app/)：發佈示例並驗證存取。
5. [認識控制台](/docs/zh-tw/getting-started/console/)：找到應用程式、伺服器、設定與帳戶。

## 平台管理

[平台管理](/docs/zh-tw/administration/)按伺服器與分組、帳戶與權限、平台維護繼續展開。需要連接外部工具時，查看其中的 [API 與 MCP](/docs/zh-tw/guides/automation/api-mcp/)。

文件中的實例地址、網域、郵箱、密碼和金鑰示例需要替換為自己的值。操作後按照對應頁面驗證實際結果；涉及資料的更新或清理，還應驗證備份和業務恢復。
