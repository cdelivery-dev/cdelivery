登入後，先從當前任務選擇入口。不同角色可見的編輯按鈕不同；看不到某個管理入口時，先核對[角色與權限](/docs/zh-tw/administration/accounts/roles/)。

## 主要入口

| 入口 | 用於什麼 |
| --- | --- |
| 概覽 | 查看平台和應用程式的整體執行情況 |
| 分組及其應用程式清單 | 找到業務應用程式、建立應用程式、查看分組資訊 |
| Insight | 設定觀測服務、存儲和資料採集 |
| Pingress | 設定 HTTP/HTTPS 入口及管理憑證 |
| 資料卷服務 | 管理提供資料卷操作能力的平台組件 |
| 伺服器 | 查看機器狀態、標籤、指標及該伺服器的資料卷 |
| Agent | 設定 AI 模型和自動值班 |
| MCP / API 金鑰 | 管理自己的接入憑據 |
| 設定 | 管理平台、使用者和消息渠道 |
| 個人帳戶 | 修改個人資料、通知綁定、密碼和兩步驟驗證 |

資料卷服務入口與伺服器上的資料卷清單不是同一層次：前者管理組件，後者管理某台機器的實際卷。使用資料卷前按[資料卷管理](/docs/zh-tw/administration/nodes/volumes/)確認組件和目標伺服器。

## 應用程式頁面

打開應用程式後，圍繞以下內容操作：

- **概覽**：查看期望副本、實際執行情況及應用程式資訊。
- **設定**：編輯映像檔、執行參數、資源、網路、檔案和存儲等設定。
- **XHealth**：設定週期性業務檢查，查看檢查結果。
- **XJob**：管理計劃任務並查看最近執行狀態。
- **指標**：查看選定時間範圍內的應用程式資源和請求指標。
- **日誌**：查看應用程式輸出，按支援的條件篩選。
- **事件**：查看平台記錄的操作和執行變化。

編輯設定後，儲存成功只表示操作已接受或設定已更新。涉及容器更新時，繼續查看副本狀態、日誌及檢查結果。

## 三種容易混淆的狀態

| 狀態 | 能說明什麼 |
| --- | --- |
| 副本執行 | 容器進程已經執行 |
| XHealth 通過 | 最近一次設定的檢查成功 |
| 用戶端存取成功 | 當前用戶端到業務入口的連線路徑可用 |

其中一項正常，不能自動推出另外兩項正常。排障時先確定失敗發生在哪條連線路徑。

## 按任務繼續閱讀

1. 部署和設定業務：進入[應用程式管理](/docs/zh-tw/guides/apps/)。
2. 查看日誌和指標：進入[日誌與指標](/docs/zh-tw/guides/observability/)。
3. 添加機器或分配帳戶：進入[平台管理](/docs/zh-tw/administration/)。
4. 接收通知或與助手對話：先設定[消息與通知](/docs/zh-tw/guides/automation/im/)。

語言和其他個人偏好在自己的帳戶中管理；AI 生成值班通知使用值班設定中的通知語言。
