## 開始之前

在準備好的伺服器上執行安裝。安裝指令需要管理員權限，並會建立平台執行所需的資源；先完成[安裝前準備](/docs/zh-tw/getting-started/requirements/)。

Linux 上按安裝器輸出檢查 Docker 和網路準備結果。macOS 上先啟動 Docker 執行環境。遇到 IPv6 準備問題時，按提示選擇繼續使用 IPv4 或退出檢查；非交互環境不要依賴人工選擇。相關行為見[網路常見問題](/docs/zh-tw/guides/networking/faq/)。

## 操作步驟

<Steps>

<Step title="執行安裝">

```sh
curl -fsSL https://cdelivery.dev/install.sh | sh
```

需要指定伺服器之間使用的地址時：

```sh
curl -fsSL https://cdelivery.dev/install.sh | sh -s -- --advertise-addr 10.0.0.10
```

將 `10.0.0.10` 替換為當前伺服器擁有、且其他伺服器可存取的地址。它不是網域，也不一定是你瀏覽器使用的公網地址。

</Step>

<Step title="開啟控制台">

安裝完成後，存取：

```text
http://SERVER_IP:9000
```

將 `SERVER_IP` 替換為你能存取的伺服器地址。macOS 通常使用 `http://localhost:9000`。通過 SSH 隧道管理遠程伺服器時，也使用隧道對應的本地地址。

</Step>

<Step title="建立首個管理員">

首次開啟控制台時，填寫姓名、電子郵件和密碼，建立第一個 Admin 帳戶。儲存後會自動登入並進入平台設定。

在平台設定頁，可設定平台網域、啟用 Insight，也可直接進入控制台。Insight 預設使用本機儲存，保留 90 天。後續在平台設定和 Insight 頁面管理。

如果已有安裝恢復執行，使用原有帳戶。不要把再次執行安裝器當作清空帳戶、重置密碼或更改伺服器通信地址的方法。

</Step>

</Steps>

## 驗證安裝結果

- 能開啟控制台並使用管理員帳戶登入。
- 伺服器清單中的地址和資源資訊符合預期。
- 能開啟分組管理及平台設定。

## 無法開啟或登入

| 現象 | 檢查順序 |
| --- | --- |
| 安裝資源無法下載 | DNS、HTTPS 出站存取、代理及安裝器的原始錯誤 |
| Docker 連接失敗 | Docker 是否啟動、當前權限、服務端版本 |
| 瀏覽器連接超時 | 伺服器地址、9000 連接埠、雲安全組、宿主防火牆 |
| 隧道存取失敗 | SSH 會話是否仍在執行、本地連接埠是否被其他程序佔用 |
| 首次設定後顯示登入頁 | 使用剛建立的帳戶登入 |
| 原管理員無法登入 | 使用[恢復管理存取](/docs/zh-tw/administration/platform/recovery/)中的現有恢復方式 |

儲存安裝器報錯的完整上下文，但在分享前移除密碼、權杖和加入憑證。需要網域存取控制台時，繼續[平台網域與存取](/docs/zh-tw/administration/platform/access/)。
