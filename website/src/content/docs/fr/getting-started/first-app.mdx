Déployez Nginx sur un port publié et vérifiez une réponse HTTP réelle.

## Préparer

Utilisez une installation opérationnelle. Admin crée le groupe ; Operator ou Admin déploie l’application. Le serveur doit pouvoir télécharger l’image publique Nginx depuis Docker Hub. Le port TCP 8080 doit être libre et accessible depuis votre ordinateur.

Pour un accès par SSH, exécutez cette commande sur votre ordinateur et laissez la session ouverte :

```sh
ssh -L 9000:127.0.0.1:9000 -L 8080:127.0.0.1:8080 your-user@server.example.com
```

## Étapes

<Steps>

<Step title="Créer un groupe">

Créez un groupe nommé `demo`.

</Step>

<Step title="Configurer l’application">

Créez l’application `hello-web` dans ce groupe avec l’image `nginx:stable-alpine`. Conservez la commande par défaut et un réplica fixe.

</Step>

<Step title="Publier un port">

Publiez le port du conteneur **80** sur le port du serveur **8080**, en TCP.

</Step>

<Step title="Déployer l’application">

Enregistrez l’application et attendez que le réplica soit en cours d’exécution.

</Step>

</Steps>

Aucun domaine, volume ou commande personnalisée n’est nécessaire. L’[image officielle](https://hub.docker.com/_/nginx) lance déjà Nginx au premier plan.

## Tester

Depuis votre ordinateur, ouvrez `http://SERVER_IP:8080` ou exécutez la commande suivante. Remplacez `SERVER_IP` par l’adresse accessible du serveur.

```sh
curl -i http://SERVER_IP:8080
```

Si vous utilisez le tunnel SSH, laissez la session ouverte et exécutez plutôt cette commande sur votre ordinateur :

```sh
curl -i http://localhost:8080
```

Attendez HTTP 200 et la page Nginx. Vérifiez aussi réplicas et journaux.

Échec de pull : registre/architecture. Arrêt du processus : commande et journaux. Timeout : mappage, adresse, pare-feu et tunnel. Une route de domaine utiliserait le port interne 80.

Pour nettoyer, supprimez application, attendez les conteneurs puis supprimez le groupe vide. Consultez la [gestion des applications](/docs/fr/guides/apps/).
