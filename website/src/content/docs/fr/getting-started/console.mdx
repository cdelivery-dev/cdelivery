La console distingue exploitation des applications, administration et réglages personnels.

## Trouver une fonction

| Zone | Fonctions |
| --- | --- |
| Groupes/applications | Configuration, réplicas, déploiement |
| Journaux/métriques | Diagnostic et ressources |
| XHealth/Guardian/XJob | Contrôles, validation, tâches |
| Serveurs | État, étiquettes, volumes, métriques |
| Paramètres | Composants, modèles, canaux, comptes, versions |
| Compte | Mot de passe, double facteur, clés, notifications |

Reader consulte les informations partagées et son compte. Operator exploite aussi les applications ; Admin gère la plateforme. Voir [autorisations](/docs/fr/administration/accounts/roles/).

## État réel

Enregistrer confirme la demande ; téléchargement, placement et démarrage peuvent continuer. Comparez réplicas souhaités/réels, journaux et requête métier.

Un graphique vide peut indiquer collecte désactivée, retard ou absence d’échantillons. Une requête échouée est différente ; absence ne signifie pas consommation nulle.

## Routine

Inspectez, modifiez puis vérifiez tâches, événements et accès. Pour supprimer, contrôlez les données conservées séparément.

Admin configure les canaux ; chacun associe son identité et ses abonnements. Consultez [observabilité](/docs/fr/guides/observability/) et [administration](/docs/fr/administration/).
