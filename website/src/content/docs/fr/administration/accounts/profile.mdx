Chaque rôle gère son compte ; e-mail et rôle sont modifiés par un administrateur.

## Mot de passe

Saisissez ancien et nouveau. Enregistrer invalide toutes les sessions, y compris celle-ci ; reconnectez-vous. Les clés API restent valides et se révoquent séparément.

En cas d’oubli, contactez Admin. Sans accès administratif, consultez [récupération](/docs/fr/administration/platform/recovery/).

## Double facteur

Scannez QR ou saisissez secret, envoyez mot de passe et code à six chiffres, confirmez activation puis testez une nouvelle connexion.

Scanner seul n’active pas. QR/secret sont confidentiels. Pour code refusé, vérifiez horloge, compte et expiration.

Désactiver exige mot de passe/code. Authentificateur perdu : reset administratif ou hôte ; ne supposez pas de codes de secours.

## Préférences

Choisissez huit langues et thème clair/sombre/système. Associez votre ID de [messagerie](/docs/fr/guides/automation/im/) et abonnez-vous séparément.

Les [clés API](/docs/fr/guides/automation/api-mcp/) sont affichées une fois ; utilisez-les plutôt qu’un cookie durable.
