CDelivery déploie des images de conteneur et facilite l’exploitation sur un ou plusieurs serveurs.

## Premiers pas

1. [Avant l’installation](/docs/fr/getting-started/requirements/) : Préparez les adresses, le réseau et l’accès à la console.
2. [Installer CDelivery](/docs/fr/getting-started/installation/) : Démarrez la plateforme et créez un compte administrateur.
3. [Déployer une première application](/docs/fr/getting-started/first-app/) : Déployez Nginx et vérifiez l’accès.

## Notions essentielles

| Objet | Fonction |
| --- | --- |
| Serveur | Fournit les ressources de calcul et le stockage local. |
| Groupe | Organise les applications et fournit un réseau partagé. |
| Application | Associe une image de conteneur, une configuration et les paramètres d’exécution souhaités. |
| Réplique | Une instance en cours d’exécution d’une application. |

Les groupes n’isolent pas les permissions des comptes ; consultez [les rôles et permissions](/docs/fr/administration/accounts/roles/). Pour conserver les données, lisez [la persistance des données](/docs/fr/guides/apps/persistence/). Les répliques et le retour arrière d’une application ne remplacent pas les sauvegardes.
