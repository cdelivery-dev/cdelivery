XHealth vérifie l’application, les stratégies de mise à jour contrôlent le remplacement des répliques, les vérifications de publication valident les changements d’applications et de bases de données, et le retour arrière restaure une configuration précédente de l’application.

## Choisir une tâche

<CardGrid>

<Card title="Configurer XHealth" href="/docs/fr/guides/release-safety/xhealth/" icon="ph:heartbeat">
  XHealth exécute les contrôles dans des tâches distinctes des conteneurs métier.
</Card>

<Card title="Stratégies de mise à jour" href="/docs/fr/guides/release-safety/update-strategy/" icon="ph:arrows-clockwise">
  Contrôlez parallélisme, ordre, observation et réaction aux échecs.
</Card>

<Card title="Vérifications de publication" href="/docs/fr/guides/release-safety/guardian/" icon="ph:shield-check">
  Vérifiez les prévisualisations avant d’appliquer les changements d’applications ou de bases de données et traitez les échecs explicitement.
</Card>

<Card title="Retour arrière et échecs" href="/docs/fr/guides/release-safety/rollback/" icon="ph:arrow-u-up-left">
  Rollback restaure une configuration précédente, pas les données ou la plateforme.
</Card>

</CardGrid>
