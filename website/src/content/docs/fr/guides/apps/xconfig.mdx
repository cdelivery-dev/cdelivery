XConfig fournit un fichier de configuration ; utilisez un volume pour les données modifiables.

Pour les fichiers d’identifiants, choisissez un secret fichier dans [Secrets](/docs/fr/guides/apps/secrets/) en sélectionnant la source **Secret** lors de l’ajout. Les instructions de téléversement et de téléchargement ci-dessous concernent les fichiers ordinaires.

## Charger

Choisissez une application compatible, un fichier non vide de 1,023,999 octets maximum et un chemin absolu de 2–255 caractères, sans `/` final.

Pour personnaliser la page d’accueil de l’application Hello :

```text
/www/index.html
```

Téléversez un fichier HTML pour remplacer les informations de la requête par votre page d’accueil. Voir l’exemple de [montage et mise à jour](/docs/fr/guides/apps/xconfig/mounting/).

## Accès et remplacement

Les utilisateurs autorisés à lire peuvent télécharger le contenu. Les secrets arbitraires ne sont pas automatiquement masqués.

Remplacer crée une nouvelle configuration et actualise la référence ; ce n’est pas une édition de fichier inscriptible dans le conteneur. Le mode volume local ne prend pas les téléversements XConfig ordinaires en charge.

## Contrôler

Vérifiez tâches, journaux et comportement dépendant du fichier. Un fichier stocké peut être ignoré si le chemin est incorrect.

Voir [montage et mise à jour](/docs/fr/guides/apps/xconfig/mounting/) et [persistance](/docs/fr/guides/apps/persistence/).
