Distingue comunicación interna, puertos publicados y rutas HTTP/HTTPS mediante Pingress.

## Elegir acceso

| Necesidad | Configuración |
| --- | --- |
| Comunicación dentro del grupo | Nombre de aplicación y puerto interno |
| Acceso TCP/UDP directo | Puerto publicado |
| Aplicación HTTP con dominio | Ruta de Pingress al puerto interno |
| HTTPS | Ruta y certificado válido |

Una ruta de dominio no necesita publicar primero el puerto y no apunta al número de puerto público.

## Resolución de problemas

Verifica DNS, conexión, TLS y respuesta por separado. Un certificado emitido no demuestra que el proceso responda correctamente. El [dominio de administración](/docs/es/administration/platform/access/) se configura aparte.
