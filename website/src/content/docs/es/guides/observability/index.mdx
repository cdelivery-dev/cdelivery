Admin habilita Insight, recolectores, almacenamiento y retención. Los registros también dependen del controlador de la aplicación. Habilitar recogida no importa el pasado.

## Consultar

Selecciona recurso, fuente y periodo correctos; las consultas históricas admiten hasta 31 días. Usa un intervalo estrecho alrededor del incidente.

Vacío puede significar falta de actividad, recogida desactivada, retraso o retención vencida. Un error de consulta significa que no terminó correctamente. No interpretes ausencia como cero.

Tras cambiar ajustes, genera actividad nueva y verifica timestamps recientes. Correlaciona petición, proceso, métricas y evento antes de modificar configuración.
