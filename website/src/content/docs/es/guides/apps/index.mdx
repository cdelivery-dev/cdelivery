Una aplicación combina imagen, ejecución, red, recursos y almacenamiento; verifica siempre su estado real.

## Decidir antes de crear

Determina grupo, nombre, persistencia, comando, puertos y capacidad. La consola no renombra aplicaciones ni las mueve entre grupos. El modo de volúmenes locales se elige al crear.

Reader consulta; Operator y Admin crean, modifican, reinician y eliminan. Grupos y recursos de servidores requieren Admin.
