Admin conecta canales; cada usuario vincula su identidad y elige suscripciones personales.

## Elegir canal

| Canal | Credenciales | Identidad personal |
| --- | --- | --- |
| [Correo](/docs/es/guides/automation/im/email/) | SMTP, IMAP opcional | Correo de cuenta |
| [Slack](/docs/es/guides/automation/im/slack/) | Tokens bot y app | Member ID |
| [Telegram](/docs/es/guides/automation/im/telegram/) | Token bot | ID numérico |
| [Discord](/docs/es/guides/automation/im/discord/) | Token bot | User ID |
| [Lark](/docs/es/guides/automation/im/lark/) | App ID y Secret | open_id |
| [Feishu](/docs/es/guides/automation/im/feishu/) | App ID y Secret | open_id |

Nombre visible, ID de grupo y bot no sustituyen al ID personal.

## Configurar y verificar

Sigue creación, permisos, publicación y recepción del canal. Guarda credenciales, vincula tu propio ID y activa notificaciones. Para conversar añade [modelo](/docs/es/guides/automation/models/) y prueba una pregunta de lectura.

Vincular otra persona puede exponerle tus notificaciones y permisos. Verifica tu identidad inmutable antes de guardar.

## Diagnóstico

Separa credenciales, red, eventos, vinculación, suscripción y modelo. Mostrar un avatar no prueba entrega ni identidad correcta. Consulta [notificaciones](/docs/es/guides/automation/im/notifications/) para roles e idioma.
