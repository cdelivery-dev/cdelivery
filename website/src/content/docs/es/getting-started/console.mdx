La consola separa operaciones de aplicaciones, administración de la plataforma y ajustes personales.

## Encontrar cada función

| Área | Operaciones |
| --- | --- |
| Grupos y aplicaciones | Configuración, réplicas y despliegue |
| Registros y métricas | Diagnóstico de procesos y recursos |
| XHealth, Guardian, XJob | Comprobaciones, validación y tareas |
| Servidores | Estado, etiquetas, métricas y volúmenes |
| Ajustes | Componentes, usuarios, modelos, canales y versiones |
| Cuenta | Contraseña, doble factor, claves y notificaciones |

Reader consulta información compartida y gestiona su cuenta. Operator también opera aplicaciones; Admin administra recursos y ajustes. Consulta [permisos](/docs/es/administration/accounts/roles/) si falta una acción.

## Configuración y ejecución

Guardar confirma la solicitud, pero descarga, planificación y arranque pueden continuar. Compara réplicas deseadas y reales, lee registros y realiza una petición de negocio.

Una gráfica vacía puede indicar recogida desactivada, retraso o ausencia de muestras. Una consulta fallida es otra situación; no interpretes datos ausentes como cero.

## Flujo habitual

Selecciona la aplicación, revisa su estado, cambia lo necesario y verifica réplicas, registros, eventos y acceso. Para eliminar recursos, comprueba los datos retenidos por separado.

Admin configura credenciales de canales; cada usuario vincula su identidad y activa suscripciones en la cuenta. Continúa con [observabilidad](/docs/es/guides/observability/) o [administración](/docs/es/administration/).
