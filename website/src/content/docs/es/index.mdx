CDelivery permite desplegar imágenes de contenedor y mantener aplicaciones desde uno o varios servidores.

## Primeros pasos

1. [Antes de instalar](/docs/es/getting-started/requirements/): Prepara las direcciones, la red y el acceso a la consola.
2. [Instalar CDelivery](/docs/es/getting-started/installation/): Inicia la plataforma y crea una cuenta de administrador.
3. [Desplegar la primera aplicación](/docs/es/getting-started/first-app/): Despliega Hello y verifica el acceso.

## Conceptos principales

| Objeto | Función |
| --- | --- |
| Servidor | Proporciona recursos de cómputo y almacenamiento local. |
| Grupo | Organiza aplicaciones y proporciona una red compartida. |
| Aplicación | Combina una imagen de contenedor, su configuración y los parámetros de ejecución deseados. |
| Réplica | Una instancia en ejecución de una aplicación. |

Los grupos no aíslan los permisos de las cuentas; consulta [roles y permisos](/docs/es/administration/accounts/roles/). Para conservar datos, lee [persistencia de datos](/docs/es/guides/apps/persistence/). Las réplicas y la reversión de aplicaciones no sustituyen las copias de seguridad.
