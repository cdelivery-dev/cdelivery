<Aside type="danger">
La desinstalación elimina recursos administrativos, aplicaciones, cuentas y credenciales, pero conserva volúmenes y descripciones.
</Aside>

## Desinstalar

Ejecuta en un terminal interactivo del servidor de gestión con Docker CLI y jq, usando el socket Unix local. Registra ajustes, imágenes y correspondencia servidor/volumen; haz copias y detén creación de recursos.

```sh
curl -fsSL https://cdelivery.dev/uninstall.sh | sh
```

Comprueba el endpoint de Docker y los recursos mostrados, escribe `y` o `Y` y pulsa Enter para confirmar. Pulsa Enter sin escribir, introduce cualquier otro texto o usa Ctrl+C para cancelar. Si no quedan recursos por eliminar, el script termina sin pedir confirmación.

Primero detiene el programa principal y luego elimina recursos gestionados. Antes de informar que ha terminado, espera hasta 120 segundos a que las redes gestionadas desaparezcan de la lista de redes del Docker local. Si se agota el tiempo, muestra las redes restantes y termina con un error. No desinstala Docker ni elimina volúmenes, DNS externo, almacenamiento de objetos o cuentas de proveedores.

## Verificar

Comprueba recursos retirados y volúmenes conservados. Contenedores salen de forma asíncrona; los offline requieren comprobación al reconectar.

Si falla un paso, corrige conexión, referencias o permisos y ejecuta el mismo comando para revisar la vista previa y confirmar de nuevo. No reinstales ni recrees nombres durante limpieza.

Borrar datos conservados exige decisión separada. Una nueva instalación crea datos administrativos nuevos; restaurar aplicaciones requiere configuración registrada y recuperación del almacenamiento.
