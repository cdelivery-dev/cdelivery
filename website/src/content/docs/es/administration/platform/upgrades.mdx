El programa principal y Pingress, Insight, Insight Agent y gestión de volúmenes tienen versiones independientes.

## Preparar

Admin revisa versión actual, disponible y notas. Comprueba descarga y arquitectura, reserva tiempo y realiza copias de los datos de negocio.

El catálogo ofrece la última versión de cada componente y la operación exige esa versión. No hay selector general de versiones históricas ni botón universal de downgrade.

## Actualizar

Selecciona versión en Ajustes → CDelivery, confirma y espera reinicio. Reabre y verifica versión, servidores, aplicaciones, eventos y conexiones API/MCP.

Actualiza componentes por separado. Verifica HTTPS tras Pingress, muestras nuevas tras Insight/recolectores y lectura de volúmenes tras cdelivery-agent. Tras reinicio, obtén nuevas credenciales de incorporación.

## Diagnosticar

Metadatos inaccesibles no significan versión actualizada. Revisa red hacia publicaciones. Para descarga fallida, comprueba arquitectura, imagen y tareas.

La [reversión de aplicación](/docs/es/guides/release-safety/rollback/) no restaura plataforma ni datos. Para login, usa [recuperación](/docs/es/administration/platform/recovery/).

Los secretos de texto usan el runtime incluido cuando cambia realmente el despliegue. Actualizar solo la plataforma no reinicia aplicaciones. Guardar sin cambios, modificar la descripción, escalar y reiniciar normalmente conserva las referencias; la reversión restaura las anteriores.
