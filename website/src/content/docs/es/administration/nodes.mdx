Identifica máquinas por ID y dirección; el nombre del host puede repetirse.

## Incorporar

Admin obtiene comando Worker o Manager en servidores. Revisa [requisitos](/docs/es/getting-started/requirements/) y ejecútalo en la máquina destino. Confirma Ready, rol, dirección y recursos; después añade etiquetas.

Worker ejecuta cargas; Manager participa también en gestión. Credenciales de incorporación duran 30 minutos y pueden reutilizarse. Tras reinicio o caducidad, obtén nuevas; cambios de permisos del emisor pueden invalidarlas. No las publiques.

## Estados

Ready, Down y Disconnected describen el estado de la conexión. Active acepta tareas nuevas. Pause detiene las nuevas asignaciones y mantiene las tareas existentes en ejecución. Drain activa el modo de vaciado, que impide nuevas asignaciones y retira las tareas existentes del servidor; no confirma que la migración haya terminado. Reachable y Unreachable indican la accesibilidad del servidor de gestión. Una alerta del recolector indica observaciones desactualizadas, no necesariamente un fallo del servidor.

Consulta la capacidad disponible en las [métricas del servidor](/docs/es/guides/observability/metrics/server/).

## Eliminar

La acción no migra aplicaciones, copia datos ni vacía automáticamente. Revisa aplicaciones fijas, volúmenes, componentes y continuidad de gestión.

No borra volúmenes ni confirma salida de contenedores offline. Reincorporar puede cambiar ID; revisa ubicación fija y etiquetas. Para fallos de unión, comprueba IP, credencial, Docker y puertos entre servidores.
