## Orden inicial

Tras crear Admin, verifica direcciones y servidores, después grupos y aplicaciones. Crea cuentas individuales y asigna roles. Añade observabilidad, dominios y canales según necesidad.

Grupos no separan permisos y etiquetas no copian datos. Revisa dependencias antes de eliminar recursos.

## Aceptación

Comprueba lista, estado real, eventos y acceso después de guardar. Las tareas y recogida pueden continuar de forma asíncrona. Para restauración, verifica datos de negocio además del contenedor.
