Die Konsole trennt Anwendungsbetrieb, Plattformverwaltung und persönliche Einstellungen.

## Bereiche

| Bereich | Aufgaben |
| --- | --- |
| Gruppen/Anwendungen | Konfiguration, Replikate, Bereitstellung |
| Logs/Metriken | Diagnose und Ressourcen |
| XHealth/Guardian/XJob | Prüfungen, Validierung, Aufgaben |
| Server | Status, Labels, Volumes, Metriken |
| Einstellungen | Komponenten, Modelle, Kanäle, Konten, Versionen |
| Konto | Passwort, Zweifaktor, Schlüssel, Benachrichtigungen |

Reader liest geteilte Daten und verwaltet sein Konto. Operator betreibt Anwendungen, Admin die Plattform. Siehe [Rechte](/docs/de/administration/accounts/roles/).

## Laufzeit prüfen

Speichern bestätigt die Anfrage; Download, Planung und Start können weiterlaufen. Soll/Ist-Replikate, Logs und Geschäftsanfrage vergleichen.

Leere Diagramme können fehlende Erfassung, Verzögerung oder keine Messwerte bedeuten. Abfragefehler sind anders; fehlend ist nicht null Verbrauch.

## Ablauf

Zustand prüfen, gezielt ändern, Aufgaben/Ereignisse/Zugriff kontrollieren. Beim Löschen erhaltene Daten getrennt prüfen.

Admin konfiguriert Kanäle; Nutzer ordnen Identität und Abonnements zu. Siehe [Beobachtung](/docs/de/guides/observability/) und [Verwaltung](/docs/de/administration/).
