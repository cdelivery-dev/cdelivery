CDelivery stellt Container-Images bereit und unterstützt den Betrieb auf einem oder mehreren Servern.

## Erste Schritte

1. [Vor der Installation](/docs/de/getting-started/requirements/): Serveradressen, Netzwerk und Konsolenzugriff vorbereiten.
2. [CDelivery installieren](/docs/de/getting-started/installation/): Plattform starten und ein Administratorkonto erstellen.
3. [Erste Anwendung bereitstellen](/docs/de/getting-started/first-app/): Nginx bereitstellen und den Zugriff prüfen.

## Grundbegriffe

| Objekt | Zweck |
| --- | --- |
| Server | Stellt Rechenressourcen und lokalen Speicher bereit. |
| Gruppe | Organisiert Anwendungen und stellt ein gemeinsames Netzwerk bereit. |
| Anwendung | Verbindet Container-Image, Konfiguration und gewünschte Laufzeiteinstellungen. |
| Replikat | Eine laufende Instanz einer Anwendung. |

Gruppen grenzen Kontoberechtigungen nicht voneinander ab; siehe [Rollen und Berechtigungen](/docs/de/administration/accounts/roles/). Für dauerhaft benötigte Daten lies [Datenpersistenz](/docs/de/guides/apps/persistence/). Replikate und Anwendungs-Rollbacks ersetzen keine Sicherungen.
