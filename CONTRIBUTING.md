# Contributing

Use [GitHub issues](https://github.com/cdelivery-dev/cdelivery/issues) to report bugs or propose changes. For bug reports, include the affected version, reproduction steps, and expected and actual behavior. Follow [SECURITY.md](SECURITY.md) for vulnerability reports.

Keep pull requests focused. Explain the problem and the change, follow existing code conventions, and update affected documentation and translations.

See [tests/README.md](tests/README.md) for Rust checks and the integration environment, and [website/README.md](website/README.md) for website and documentation development. Validate the parts affected by your change and include the commands, results, and any remaining verification gaps in the pull request.

By intentionally submitting a contribution for inclusion, you agree to license it under [Apache License 2.0](LICENSE). You retain your copyright and must have the right to submit the contribution. No separate CLA or DCO sign-off is required. Preserve third-party licenses, attribution, and notices, and identify imported or modified third-party material in the pull request.
