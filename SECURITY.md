# Security

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/cdelivery-dev/cdelivery/security/advisories/new). Include the affected version, impact, and reproduction steps. Remove credentials, private keys, and personal data from examples and logs.

Keep vulnerability details out of public issues and pull requests while the report is being investigated. Use [GitHub issues](https://github.com/cdelivery-dev/cdelivery/issues) for ordinary bugs and support questions.
